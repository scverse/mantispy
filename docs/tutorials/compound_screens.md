# Compound screens

Compound screens treat wells with small molecules, usually at one or several doses, against a plate of negative controls.
These tutorials call hits, group compounds by mechanism of action, test which pathways are enriched and fit dose responses.
Start with the hits tutorial; the others build on its result.
