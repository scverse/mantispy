# mantispy 0.3.0 "Batch correction and evaluation" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the correction steps of the Broad recipe (sphering, Harmony, plate-position correction, confounder regression) plus the metrics needed to judge them, with copairs mAP as the central readout, and make the whole recipe reproducible end to end on BBBC021.

**Architecture:** Corrections are `pp` functions that either rewrite `X`/a layer (sphering, median polish, regression) or add an `obsm` representation (Harmony). Evaluation splits in two: `ms.tl` holds the profiling-specific readouts (mAP, percent replicating, grit, similarity) and a new `ms.metrics` module holds the scib-style integration metrics, all returning tidy `DataFrame`s so `evaluate_correction` can stack them into one comparison table. Everything at this level runs on aggregated (well or perturbation) profiles — the default resolution — so the data is small and none of it needs the streaming path.

**Tech Stack:** Everything from 0.2 plus `copairs` and `harmonypy` as hard dependencies. Dev-only additions: `scib`.

**Spec:** `mantispy_release_plan.md` (section "0.3.0 Batch correction and evaluation")

**Prerequisite:** `docs/superpowers/plans/2026-09-07-mantispy-0.2.0-trustworthy-profiles.md` complete and released.

## Global Constraints

All 0.1.0 and 0.2.0 global constraints carry forward. In addition:

- `scib` is **test-only**; add it to the `FORBIDDEN` list in `tests/test_no_reference_imports.py` (it is already there — verify).
- `copairs` and `harmonypy` are hard dependencies, imported lazily inside the functions that use them so that `import mantispy` stays fast.
- `ms.pp.pca` and `ms.pp.neighbors` are **deliberately not implemented**. The docs say "use `sc.pp.pca` / `sc.pp.neighbors`". A test asserts they do not exist, so nobody adds them by reflex.
- Every metric function returns a tidy `pandas.DataFrame` with at least the columns `metric`, `representation`, `value` — never a bare float — so results stack.
- All randomized procedures take `seed: int = 0` and are reproducible.
- Corrections at cell resolution are permitted but the default and documented path is well resolution; `warn_resolution` is used where the distinction matters.

```python
# src/mantispy/pp/_sphere.py
"""Whitening (sphering) fitted on control profiles."""

from __future__ import annotations

import numpy as np
from anndata import AnnData

from .._core._chunks import get_matrix, group_codes
from .._core._utils import maybe_copy, record_params
from ._normalize import _reference_mask

METHODS = ("ZCA", "ZCA-cor", "PCA", "PCA-cor")


def _fit(reference: np.ndarray, method: str, epsilon: float):
    """Return ``(center, scale, W, eigenvalues)`` for the requested whitening."""
    center = np.nanmean(reference, axis=0)
    centered = reference - center

    if method.endswith("-cor"):
        scale = np.nanstd(centered, axis=0, ddof=1)
        scale[scale == 0] = 1.0
        centered = centered / scale
    else:
        scale = np.ones(reference.shape[1])

    covariance = np.cov(np.nan_to_num(centered, nan=0.0), rowvar=False)
    eigenvalues, eigenvectors = np.linalg.eigh(covariance)
    order = np.argsort(eigenvalues)[::-1]
    eigenvalues, eigenvectors = eigenvalues[order], eigenvectors[:, order]

    inverse_root = np.diag(1.0 / np.sqrt(np.clip(eigenvalues, 0.0, None) + epsilon))
    if method.startswith("ZCA"):
        W = eigenvectors @ inverse_root @ eigenvectors.T
    else:
        W = eigenvectors @ inverse_root
    return center, scale, W, eigenvalues


def sphere(
    adata: AnnData,
    method: str = "ZCA-cor",
    reference: str | None = "negcon",
    epsilon: float = 1e-6,
    by: str | None = None,
    key_added: str | None = None,
    copy: bool = False,
) -> AnnData | None:
    """Whiten profiles using a transform fitted on reference (control) rows."""
    if method not in METHODS:
        raise ValueError(f"method must be one of {METHODS}, got {method!r}")
    adata = maybe_copy(adata, copy)

    X = get_matrix(adata).astype(np.float64)
    mask = _reference_mask(adata, reference)
    if not mask.any():
        raise ValueError(f"no reference rows selected by reference={reference!r}")

    codes, keys = group_codes(adata, by)
    out = np.empty_like(X)
    spectra = []
    for g in range(len(keys)):
        rows = np.flatnonzero(codes == g)
        reference_rows = rows[mask[rows]]
        if reference_rows.size == 0:
            raise ValueError(f"no reference rows in group {keys[g]!r}")
        center, scale, W, eigenvalues = _fit(X[reference_rows], method, epsilon)
        out[rows] = ((X[rows] - center) / scale) @ W
        spectra.append(eigenvalues)

    result = out.astype(np.float32)
    if key_added is None:
        adata.X = result
    else:
        adata.layers[key_added] = result

    adata.uns.setdefault("mantispy", {})["sphere"] = {
        "method": method, "eigenvalues": np.stack(spectra)
    }
    record_params(
        adata,
        "sphere",
        {"method": method, "reference": reference, "epsilon": epsilon, "by": by,
         "key_added": key_added},
    )
    return adata if copy else None
```

```python
"""Spherize equivalence against pinned pycytominer."""

import numpy as np
import pytest

import mantispy as ms
from mantispy.datasets import synthetic_plate

pycytominer = pytest.importorskip("pycytominer")


@pytest.fixture
def wells():
    cells = synthetic_plate(n_plates=2, n_wells=48, n_cells=20, n_features=15, seed=3)
    return ms.tl.aggregate(cells, min_cells=0)


@pytest.mark.parametrize("method", ["ZCA", "ZCA-cor", "PCA", "PCA-cor"])
def test_sphere_equivalence(wells, method):
    frame = ms.get.to_dataframe(wells)
    features = list(wells.var_names)
    expected = pycytominer.normalize(
        profiles=frame,
        features=features,
        meta_features=[c for c in frame.columns if c.startswith("Metadata_")],
        method="spherize",
        spherize_method=method,
        spherize_center=True,
        samples="Metadata_Control == True",
    )
    ms.pp.sphere(wells, method=method, reference="negcon")
    actual = wells.X.astype(np.float64)
    reference = expected[features].to_numpy(dtype=np.float64)

    # Whitening is defined up to the sign of each eigenvector; compare up to column sign.
    signs = np.sign((actual * reference).sum(axis=0))
    signs[signs == 0] = 1.0
    np.testing.assert_allclose(actual * signs, reference, rtol=1e-5, atol=1e-5)
```

  - `correct_plate_position(adata, method="median_polish", by="Metadata_Plate", reference=None, max_iter=10, tol=1e-4, key_added=None, copy=False) -> AnnData | None`
    Tukey median polish of the row × column well matrix, per plate, per feature; the corrected value is the residual plus the plate grand median. `reference="negcon"` fits the row/column effects on control wells only and subtracts them from all wells. Stores the fitted effects in `uns["mantispy"]["plate_position"]`.
  - `regress_out(adata, keys=("Metadata_CellCount",), by="Metadata_Plate", key_added=None, copy=False) -> AnnData | None`
    Per group, per feature: OLS on `[1, *keys]`, keep `intercept + residual`. Non-numeric keys are one-hot encoded with the first level dropped.

```python
"""Batch, plate-position and confounder corrections."""

from __future__ import annotations

from collections.abc import Sequence

import numpy as np
import pandas as pd

from .._core._chunks import get_matrix, group_codes
from .._core._utils import maybe_copy, record_params
from .._core.plate import well_col, well_row

def harmony(
    adata: AnnData,
    key: str = "Metadata_Batch",
    basis: str = "X_pca",
    key_added: str = "X_harmony",
    copy: bool = False,
    **harmonypy_kwargs,
) -> AnnData | None:
    """Run Harmony on an existing embedding."""
    import harmonypy

    adata = maybe_copy(adata, copy)
    if basis not in adata.obsm:
        raise KeyError(
            f"obsm has no {basis!r}; compute it first, e.g. `sc.pp.pca(adata, n_comps=50)`"
        )
    if key not in adata.obs:
        raise KeyError(f"obs has no column {key!r}")

    result = harmonypy.run_harmony(
        adata.obsm[basis], adata.obs, vars_use=[key], **harmonypy_kwargs
    )
    corrected = np.asarray(result.Z_corr).T
    adata.obsm[key_added] = np.ascontiguousarray(corrected, dtype=np.float32)
    record_params(adata, "harmony", {"key": key, "basis": basis, "key_added": key_added})
    return adata if copy else None


def _median_polish(matrix: np.ndarray, max_iter: int, tol: float):
    """Tukey median polish; returns ``(grand, row_effects, col_effects, residual)``."""
    residual = matrix.copy()
    grand = 0.0
    row_effects = np.zeros(matrix.shape[0])
    col_effects = np.zeros(matrix.shape[1])
    previous = np.inf
    for _ in range(max_iter):
        row_medians = np.nanmedian(residual, axis=1)
        row_medians = np.nan_to_num(row_medians, nan=0.0)
        residual -= row_medians[:, None]
        row_effects += row_medians
        delta = np.nanmedian(col_effects)
        col_effects -= delta
        grand += delta

        col_medians = np.nanmedian(residual, axis=0)
        col_medians = np.nan_to_num(col_medians, nan=0.0)
        residual -= col_medians[None, :]
        col_effects += col_medians
        delta = np.nanmedian(row_effects)
        row_effects -= delta
        grand += delta

        current = np.nansum(np.abs(residual))
        if abs(previous - current) < tol:
            break
        previous = current
    return grand, row_effects, col_effects, residual


def correct_plate_position(
    adata: AnnData,
    method: str = "median_polish",
    by: str = "Metadata_Plate",
    reference: str | None = None,
    max_iter: int = 10,
    tol: float = 1e-4,
    key_added: str | None = None,
    copy: bool = False,
) -> AnnData | None:
    """Remove row and column position effects per plate, per feature."""
    if method != "median_polish":
        raise ValueError(f"method must be 'median_polish', got {method!r}")
    adata = maybe_copy(adata, copy)

    X = get_matrix(adata).astype(np.float64)
    rows = np.array([well_row(w) for w in adata.obs["Metadata_Well"]])
    cols = np.array([well_col(w) for w in adata.obs["Metadata_Well"]])
    n_rows, n_cols = rows.max() + 1, cols.max() + 1

    fit_mask = _reference_mask(adata, reference)
    codes, keys = group_codes(adata, by)
    out = X.copy()
    effects: dict[str, dict] = {}

    for g, key in enumerate(keys):
        selected = np.flatnonzero(codes == g)
        fit_rows = selected[fit_mask[selected]]
        if fit_rows.size == 0:
            raise ValueError(f"no reference rows in group {key!r}")
        row_store = np.zeros((adata.n_vars, n_rows))
        col_store = np.zeros((adata.n_vars, n_cols))
        for j in range(adata.n_vars):
            grid = np.full((n_rows, n_cols), np.nan)
            grid[rows[fit_rows], cols[fit_rows]] = X[fit_rows, j]
            _, row_effect, col_effect, _ = _median_polish(grid, max_iter, tol)
            row_store[j], col_store[j] = row_effect, col_effect
            out[selected, j] -= row_effect[rows[selected]] + col_effect[cols[selected]]
        effects[str(key)] = {"row": row_store, "col": col_store}

    result = out.astype(np.float32)
    if key_added is None:
        adata.X = result
    else:
        adata.layers[key_added] = result
    adata.uns.setdefault("mantispy", {})["plate_position"] = effects
    record_params(
        adata,
        "correct_plate_position",
        {"method": method, "by": by, "reference": reference, "max_iter": max_iter,
         "key_added": key_added},
    )
    return adata if copy else None


def _design(adata: AnnData, keys: Sequence[str], rows: np.ndarray) -> np.ndarray:
    columns = [np.ones(rows.size)]
    for key in keys:
        values = adata.obs[key].iloc[rows]
        if pd.api.types.is_numeric_dtype(values):
            columns.append(values.to_numpy(dtype=float))
        else:
            dummies = pd.get_dummies(values, drop_first=True, dtype=float)
            columns.extend(dummies.to_numpy().T)
    return np.column_stack(columns)


def regress_out(
    adata: AnnData,
    keys: Sequence[str] = ("Metadata_CellCount",),
    by: str | None = "Metadata_Plate",
    key_added: str | None = None,
    copy: bool = False,
) -> AnnData | None:
    """Regress confounders out of every feature, per group."""
    adata = maybe_copy(adata, copy)
    missing = [key for key in keys if key not in adata.obs]
    if missing:
        raise KeyError(f"obs is missing regression key(s): {missing}")

    X = get_matrix(adata).astype(np.float64)
    codes, group_keys = group_codes(adata, by)
    out = X.copy()
    for g in range(len(group_keys)):
        rows = np.flatnonzero(codes == g)
        design = _design(adata, keys, rows)
        block = np.nan_to_num(X[rows], nan=0.0)
        coefficients, *_ = np.linalg.lstsq(design, block, rcond=None)
        fitted = design @ coefficients
        out[rows] = block - fitted + coefficients[0]

    result = out.astype(np.float32)
    if key_added is None:
        adata.X = result
    else:
        adata.layers[key_added] = result
    record_params(adata, "regress_out", {"keys": list(keys), "by": by, "key_added": key_added})
    return adata if copy else None
```

```python
# src/mantispy/tl/_map.py
"""Mean average precision via copairs."""

from __future__ import annotations

from collections.abc import Sequence

import numpy as np
from anndata import AnnData

from .._core._chunks import get_matrix
from .._core._utils import maybe_copy, record_params, warn_resolution

_MODES = {
    "activity": {
        "pos_sameby": ["Metadata_Perturbation"],
        "pos_diffby": [],
        "neg_sameby": [],
        "neg_diffby": ["Metadata_Perturbation"],
    },
    "consistency": {
        "pos_sameby": ["Metadata_Perturbation"],
        "pos_diffby": ["Metadata_Plate"],
        "neg_sameby": [],
        "neg_diffby": ["Metadata_Perturbation"],
    },
}


def map(  # noqa: A001 - mirrors the metric's name, as in the spec
    adata: AnnData,
    pos_sameby: Sequence[str] | None = None,
    pos_diffby: Sequence[str] = (),
    neg_sameby: Sequence[str] = (),
    neg_diffby: Sequence[str] = (),
    mode: str | None = None,
    reference: str = "negcon",
    use_rep: str | None = None,
    null_size: int = 10_000,
    threshold: float = 0.05,
    seed: int = 0,
    key_added: str = "map",
    copy: bool = False,
) -> AnnData | None:
    """Mean average precision of each perturbation group, with a permutation null."""
    from copairs import map as copairs_map

    explicit = any([pos_sameby, pos_diffby, neg_sameby, neg_diffby])
    if mode is not None and explicit:
        raise ValueError("pass either mode= or explicit pos_*/neg_* arguments, not both")
    if mode is not None:
        if mode not in _MODES:
            raise ValueError(f"mode must be one of {tuple(_MODES)}, got {mode!r}")
        settings = _MODES[mode]
    else:
        if not pos_sameby:
            raise ValueError("pass pos_sameby= or mode=")
        settings = {
            "pos_sameby": list(pos_sameby), "pos_diffby": list(pos_diffby),
            "neg_sameby": list(neg_sameby), "neg_diffby": list(neg_diffby),
        }

    adata = maybe_copy(adata, copy)
    warn_resolution(adata, "well")

    features = (
        np.asarray(adata.obsm[use_rep], dtype=np.float32) if use_rep else get_matrix(adata)
    )
    meta = adata.obs[[c for c in adata.obs.columns if c.startswith("Metadata_")]].reset_index(drop=True)

    average_precision = copairs_map.average_precision(meta, features, **settings)
    table = copairs_map.mean_average_precision(
        average_precision, sameby=settings["pos_sameby"], null_size=null_size,
        threshold=threshold, seed=seed,
    )

    adata.uns.setdefault("mantispy", {})[key_added] = table

    lookup = table.set_index(settings["pos_sameby"])
    index = adata.obs[settings["pos_sameby"]]
    adata.obs[key_added] = lookup["mean_average_precision"].reindex(
        index.itertuples(index=False, name=None) if len(settings["pos_sameby"]) > 1
        else index.iloc[:, 0]
    ).to_numpy()
    adata.obs[f"{key_added}_qvalue"] = lookup["corrected_p_value"].reindex(
        index.itertuples(index=False, name=None) if len(settings["pos_sameby"]) > 1
        else index.iloc[:, 0]
    ).to_numpy()

    record_params(
        adata,
        "map",
        {**settings, "mode": mode, "use_rep": use_rep, "null_size": null_size,
         "threshold": threshold, "seed": seed, "key_added": key_added},
    )
    return adata if copy else None
```

```python
import numpy as np
from anndata import AnnData

from .._core._chunks import get_matrix
from .._core._utils import maybe_copy, record_params

METRICS = ("cosine", "pearson")


def _similarity_matrix(values: np.ndarray, metric: str) -> np.ndarray:
    values = np.nan_to_num(np.asarray(values, dtype=np.float64), nan=0.0)
    if metric == "pearson":
        values = values - values.mean(axis=1, keepdims=True)
    norms = np.linalg.norm(values, axis=1, keepdims=True)
    norms[norms == 0] = 1.0
    unit = values / norms
    matrix = unit @ unit.T
    np.fill_diagonal(matrix, 1.0)
    return matrix.astype(np.float32)


def similarity(
    adata: AnnData,
    metric: str = "cosine",
    use_rep: str | None = None,
    key_added: str = "similarity",
    copy: bool = False,
) -> AnnData | None:
    """Pairwise profile similarity into ``obsp``."""
    if metric not in METRICS:
        raise ValueError(f"metric must be one of {METRICS}, got {metric!r}")
    adata = maybe_copy(adata, copy)
    values = adata.obsm[use_rep] if use_rep else get_matrix(adata)
    adata.obsp[key_added] = _similarity_matrix(values, metric)
    record_params(adata, "similarity", {"metric": metric, "use_rep": use_rep, "key_added": key_added})
    return adata if copy else None
```

```python
"""Replicate reproducibility metrics."""

from __future__ import annotations

import numpy as np
import pandas as pd
from anndata import AnnData

from .._core._chunks import get_matrix, group_codes
from .._core._utils import maybe_copy, record_params, warn_resolution
from ._similarity import _similarity_matrix


def _values(adata: AnnData, use_rep: str | None) -> np.ndarray:
    return np.asarray(adata.obsm[use_rep]) if use_rep else get_matrix(adata)


def percent_replicating(
    adata: AnnData,
    groupby: str = "Metadata_Perturbation",
    metric: str = "pearson",
    use_rep: str | None = None,
    null_size: int = 10_000,
    quantile: float = 0.95,
    seed: int = 0,
    key_added: str = "percent_replicating",
    copy: bool = False,
) -> AnnData | None:
    """Median replicate correlation against a non-replicate permutation null."""
    adata = maybe_copy(adata, copy)
    warn_resolution(adata, "well")

    matrix = _similarity_matrix(_values(adata, use_rep), metric).astype(np.float64)
    codes, keys = group_codes(adata, groupby)
    rng = np.random.default_rng(seed)

    rows, cols = np.triu_indices(adata.n_obs, k=1)
    same_group = codes[rows] == codes[cols]
    non_replicate = matrix[rows[~same_group], cols[~same_group]]

    records = []
    for g, key in enumerate(keys):
        members = np.flatnonzero(codes == g)
        if members.size < 2:
            continue
        pair_rows, pair_cols = np.triu_indices(members.size, k=1)
        observed = float(np.median(matrix[members[pair_rows], members[pair_cols]]))
        n_pairs = pair_rows.size
        null = np.array(
            [np.median(rng.choice(non_replicate, size=n_pairs, replace=True))
             for _ in range(null_size)]
        )
        threshold = float(np.quantile(null, quantile))
        records.append(
            {
                "group": key, "n_replicates": int(members.size),
                "median_replicate_correlation": observed,
                "null_threshold": threshold, "is_replicating": observed > threshold,
            }
        )

    table = pd.DataFrame(records)
    store = adata.uns.setdefault("mantispy", {})
    store[key_added] = table
    store[f"{key_added}_summary"] = {
        "fraction_replicating": float(table["is_replicating"].mean()) if len(table) else float("nan"),
        "n_groups": int(len(table)),
    }
    record_params(
        adata,
        "percent_replicating",
        {"groupby": groupby, "metric": metric, "null_size": null_size,
         "quantile": quantile, "seed": seed, "key_added": key_added},
    )
    return adata if copy else None


def grit(
    adata: AnnData,
    groupby: str = "Metadata_Perturbation",
    reference: str = "negcon",
    metric: str = "pearson",
    use_rep: str | None = None,
    key_added: str = "grit",
    copy: bool = False,
) -> AnnData | None:
    """Grit z-score of each replicate against the control similarity distribution."""
    adata = maybe_copy(adata, copy)
    warn_resolution(adata, "well")

    control_column = "Metadata_Control" if reference == "negcon" else reference
    if control_column not in adata.obs:
        raise KeyError(f"obs has no column {control_column!r}")
    is_control = adata.obs[control_column].to_numpy(dtype=bool)
    if not is_control.any():
        raise ValueError(f"no reference rows selected by reference={reference!r}")

    matrix = _similarity_matrix(_values(adata, use_rep), metric).astype(np.float64)
    codes, keys = group_codes(adata, groupby)

    per_replicate = np.full(adata.n_obs, np.nan)
    for g in range(len(keys)):
        members = np.flatnonzero(codes == g)
        if members.size < 2:
            continue
        for i in members:
            others = members[members != i]
            control_similarity = matrix[i, is_control & (np.arange(adata.n_obs) != i)]
            mean, sd = control_similarity.mean(), control_similarity.std(ddof=1)
            if sd == 0:
                continue
            per_replicate[i] = float(np.mean((matrix[i, others] - mean) / sd))

    adata.obs[key_added] = per_replicate
    table = (
        pd.DataFrame({"group": keys[codes], key_added: per_replicate})
        .groupby("group", observed=True)[key_added]
        .agg(["mean", "count"])
        .reset_index()
        .rename(columns={"mean": key_added, "count": "n_replicates"})
    )
    adata.uns.setdefault("mantispy", {})[key_added] = table
    record_params(
        adata, "grit",
        {"groupby": groupby, "reference": reference, "metric": metric, "key_added": key_added},
    )
    return adata if copy else None
```

```python
# src/mantispy/metrics/_silhouette.py
"""Silhouette-based integration metrics (scib definitions, native implementation)."""

from __future__ import annotations

import numpy as np
import pandas as pd
from anndata import AnnData
from sklearn.metrics import silhouette_samples, silhouette_score


def _embedding(adata: AnnData, use_rep: str) -> np.ndarray:
    if use_rep not in adata.obsm:
        raise KeyError(f"obsm has no {use_rep!r}; compute it first, e.g. `sc.pp.pca(adata)`")
    return np.asarray(adata.obsm[use_rep], dtype=np.float64)


def silhouette_label(
    adata: AnnData, label_key: str, use_rep: str = "X_pca"
) -> pd.DataFrame:
    """Mean silhouette over ``label_key``, rescaled to ``[0, 1]``."""
    embedding = _embedding(adata, use_rep)
    labels = adata.obs[label_key].to_numpy()
    value = (silhouette_score(embedding, labels) + 1.0) / 2.0
    return pd.DataFrame(
        [{"metric": "silhouette_label", "representation": use_rep, "key": label_key,
          "value": float(value)}]
    )


def silhouette_batch(
    adata: AnnData, label_key: str, batch_key: str, use_rep: str = "X_pca"
) -> pd.DataFrame:
    """scib batch ASW: per label, ``1 - mean|silhouette(batch)|``, averaged over labels."""
    embedding = _embedding(adata, use_rep)
    labels = adata.obs[label_key].to_numpy()
    batches = adata.obs[batch_key].to_numpy()

    scores = []
    for label in pd.unique(labels):
        rows = labels == label
        if len(np.unique(batches[rows])) < 2 or rows.sum() < 3:
            continue
        silhouettes = silhouette_samples(embedding[rows], batches[rows])
        scores.append(float(np.mean(1.0 - np.abs(silhouettes))))
    value = float(np.mean(scores)) if scores else float("nan")
    return pd.DataFrame(
        [{"metric": "silhouette_batch", "representation": use_rep, "key": batch_key,
          "value": value}]
    )
```

```python
"""Principal-component regression metrics."""

from __future__ import annotations

from collections.abc import Sequence

import numpy as np
import pandas as pd
from anndata import AnnData

from ._silhouette import _embedding


def _r_squared(component: np.ndarray, covariate: pd.Series) -> float:
    if pd.api.types.is_numeric_dtype(covariate):
        design = np.column_stack([np.ones(component.size), covariate.to_numpy(dtype=float)])
    else:
        dummies = pd.get_dummies(covariate, drop_first=True, dtype=float).to_numpy()
        design = np.column_stack([np.ones(component.size), dummies])
    coefficients, *_ = np.linalg.lstsq(design, component, rcond=None)
    residual = component - design @ coefficients
    total = float(np.sum((component - component.mean()) ** 2))
    return 0.0 if total == 0 else float(1.0 - np.sum(residual**2) / total)


def pc_regression(
    adata: AnnData, key: str, use_rep: str = "X_pca", n_comps: int | None = None
) -> pd.DataFrame:
    """Variance-weighted R^2 of the principal components on ``key``."""
    embedding = _embedding(adata, use_rep)
    if n_comps is not None:
        embedding = embedding[:, :n_comps]
    covariate = adata.obs[key]
    variances = embedding.var(axis=0, ddof=1)
    weights = variances / variances.sum()
    r_squared = np.array([_r_squared(embedding[:, i], covariate) for i in range(embedding.shape[1])])
    return pd.DataFrame(
        [{"metric": "pc_regression", "representation": use_rep, "key": key,
          "value": float(np.sum(weights * r_squared))}]
    )


def batch_variance_explained(
    adata: AnnData, keys: Sequence[str], use_rep: str = "X_pca"
) -> pd.DataFrame:
    """:func:`pc_regression` for several covariates, stacked."""
    return pd.concat([pc_regression(adata, key, use_rep) for key in keys], ignore_index=True)
```

```python
# src/mantispy/metrics/_lisi.py
"""Local inverse Simpson's index."""

from __future__ import annotations

import numpy as np
import pandas as pd
from anndata import AnnData
from sklearn.neighbors import NearestNeighbors

from ._silhouette import _embedding


def _simpson(distances: np.ndarray, labels: np.ndarray, perplexity: float) -> float:
    """Inverse Simpson index of one neighbourhood under a calibrated Gaussian kernel."""
    beta, lower, upper = 1.0, -np.inf, np.inf
    target = np.log(perplexity)
    probabilities = np.exp(-distances * beta)
    for _ in range(50):
        total = probabilities.sum()
        if total == 0:
            return 1.0
        entropy = np.log(total) + beta * np.sum(distances * probabilities) / total
        if abs(entropy - target) < 1e-5:
            break
        if entropy > target:
            lower = beta
            beta = beta * 2 if upper == np.inf else (beta + upper) / 2
        else:
            upper = beta
            beta = beta / 2 if lower == -np.inf else (beta + lower) / 2
        probabilities = np.exp(-distances * beta)
    weights = probabilities / probabilities.sum()
    fractions = np.array([weights[labels == value].sum() for value in np.unique(labels)])
    return float(1.0 / np.sum(fractions**2))


def lisi(
    adata: AnnData, key: str, use_rep: str = "X_pca", perplexity: float = 30
) -> pd.DataFrame:
    """Median LISI over cells; use a batch key for iLISI, a label key for cLISI."""
    embedding = _embedding(adata, use_rep)
    labels = adata.obs[key].to_numpy()
    n_neighbors = min(int(perplexity * 3), adata.n_obs - 1)
    distances, indices = (
        NearestNeighbors(n_neighbors=n_neighbors + 1).fit(embedding).kneighbors(embedding)
    )
    scores = [
        _simpson(distances[i, 1:] ** 2, labels[indices[i, 1:]], perplexity)
        for i in range(adata.n_obs)
    ]
    return pd.DataFrame(
        [{"metric": "lisi", "representation": use_rep, "key": key,
          "value": float(np.median(scores))}]
    )
```

```python
# tests/test_broad_recipe_bbbc021.py
"""The full Broad recipe, end to end, on BBBC021."""

import pytest
import scanpy as sc

import mantispy as ms


@pytest.mark.network
@pytest.mark.slow
def test_broad_recipe_runs_end_to_end():
    adata = ms.datasets.bbbc021()

    ms.pp.normalize(adata, method="mad_robustize", by="Metadata_Plate", reference="negcon")
    ms.pp.feature_select(adata)
    adata = ms.pp.subset_features(adata)
    ms.pp.sphere(adata, method="ZCA-cor", reference="negcon")
    sc.pp.pca(adata, n_comps=min(50, adata.n_vars - 1))
    ms.pp.harmony(adata, key="Metadata_Plate")
    ms.tl.map(adata, mode="activity", null_size=1000, seed=0)

    table = adata.uns["mantispy"]["map"]
    assert len(table) > 0
    assert table["mean_average_precision"].between(0, 1).all()
    # compounds with a known MOA should be more active than DMSO
    annotated = adata.obs.dropna(subset=["Metadata_MOA"])
    assert annotated["map"].median() > adata.obs.loc[adata.obs["Metadata_Control"], "map"].median()


@pytest.mark.network
@pytest.mark.slow
def test_evaluate_correction_ranks_harmony_above_raw_pca():
    adata = ms.datasets.bbbc021()
    ms.pp.normalize(adata, by="Metadata_Plate", reference="negcon")
    sc.pp.pca(adata, n_comps=min(50, adata.n_vars - 1))
    ms.pp.harmony(adata, key="Metadata_Plate")

    table = ms.metrics.evaluate_correction(
        adata, reps=("X_pca", "X_harmony"),
        label_key="Metadata_MOA", batch_key="Metadata_Plate",
    )
    pcr = table[table["metric"] == "pc_regression"].set_index("representation")["value"]
    assert pcr["X_harmony"] < pcr["X_pca"]
```

## Self-review notes

- **Spec coverage.** `sphere` → Task 2; `harmony`, `correct_plate_position`, `regress_out` → Task 3; `pca`/`neighbors` documented as scanpy calls and guarded by a test → Task 3, Step 6; `map` → Task 4; `percent_replicating`, `grit`, `similarity` → Task 5; the whole `ms.metrics` module including `evaluate_correction` → Task 6; all seven `pl` functions → Task 7; the four named tests (Spherize equivalence, median polish recovers gradients, `tl.map` equals copairs, metrics vs scib) → Tasks 2, 3, 4, 6; the exit criterion "full Broad recipe reproducible on BBBC021" → Task 8; tutorials 05/06 → Task 9.
- **Additions beyond the spec.** The synthetic generator's batch/rotation/confounder parameters (Task 1) — required to test any of the corrections against ground truth; `tests/test_no_pca_wrapper.py` — a guard, not a feature.
- **Deliberate softening.** The spec's exit criterion says the correction metrics "reproduce scib values on the fixture". That is kept as a hard gate for silhouette and PC regression, where the definitions are unambiguous. LISI is allowed a documented `xfail` because scib's LISI runs on its own kNN graph rather than an embedding, which is an implementation difference, not a correctness one. This is the only loosening in the plan; it is recorded in the changelog.
- **Naming consistency.** `use_rep` is the representation argument everywhere (`map`, `similarity`, `percent_replicating`, `grit`, every metric); `key_added` is the output-name argument everywhere; `reference="negcon"` resolves to `Metadata_Control` in `normalize`, `sphere`, `correct_plate_position` and `grit` through the shared `_reference_mask`. Metric frames always carry `metric` / `representation` / `key` / `value`.
- **Performance note carried to 0.5.** `percent_replicating`'s null loop and `similarity`'s dense `obsp` matrix are both O(n²) in profile count. At well resolution across a full JUMP-scale run that is the first thing to hit — flag it for the 0.5 benchmark suite rather than optimizing it now.
