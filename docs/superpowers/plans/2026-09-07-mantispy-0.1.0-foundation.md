# mantispy 0.1.0 "Foundation" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A user can go from a CellProfiler `ExportToSpreadsheet` directory to normalized, aggregated well-level profiles in ten lines of Python, and the on-disk AnnData contract is fixed and validated.

**Architecture:** A thin scanpy-shaped package (`ms.io` / `ms.pp` / `ms.tl` / `ms.get` / `ms.pl` / `ms.datasets`) over AnnData. All heavy per-group reductions go through one chunk iterator (`_core._chunks.iter_groups`) and numba kernels that take a group-code array, so the same code paths work in-memory today and backed later. Feature semantics live in a single parser (`_core.features.parse_feature_names`) whose output populates `adata.var`; nothing downstream re-parses names.

**Tech Stack:** Python ≥3.11, anndata, scanpy, numpy, numba, pandas, scipy, matplotlib, pooch. Dev-only: pytest, pytest-mpl, pycytominer, ruff, pre-commit.

**Spec:** `mantispy_release_plan.md` (section "0.1.0 Foundation")

## Global Constraints

- Package name `mantispy`, imported as `import mantispy as ms`. `src/` layout, scverse cookiecutter conventions.
- License BSD-3-Clause. Target: scverse core package.
- `SCHEMA_VERSION = "0.1"`. Every written file stamps `adata.uns["mantispy"]["schema_version"]`.
- Metadata columns in `obs` use the `Metadata_` prefix. OPS columns are reserved in the schema constants but unused.
- Feature names follow CellProfiler grammar; cp_measure format is the recommended canonical form.
- **AnnData only.** No images, masks, SpatialData, coordinate systems, or pixel access anywhere in this release. Image-level information comes exclusively from CellProfiler `Image.csv` columns.
- No `pertpy`, `squidpy`, `copairs`, `decoupler`, `harmonypy` imports in 0.1.0.
- `pycytominer` is a **dev/test dependency only**. It must not be imported from `src/mantispy/**`. A test enforces this.
- All feature matrices are `float32` on disk and in `X`. Intermediate statistics may be `float64`.
- Every public function that mutates records its call into `adata.uns["mantispy"]["params"][<func_name>]`.
- Every public function supports `copy: bool = False` and returns `AnnData | None` accordingly.
- Default resolution of a written object is recorded in `uns["mantispy"]["resolution"]` (`"cell"` | `"well"` | `"perturbation"`). It is **advisory, not enforced**: helpers warn on mismatch, they never raise.

## Deviations from the release plan (decided here, carry into the doc)

1. **`tl.aggregate` dispatches to `sc.get.aggregate` when the matrix has no NaN.** Verified on scanpy 1.12.4: `sc.get.aggregate` supports `mean`, `median`, `sum`, `var`, `count_nonzero`, multi-column `by`, and a `mask=`, and it returns `obs["n_obs_aggregated"]` (our `Metadata_CellCount`) for free. Measured at 200k x 1000 over 384 groups: mean 0.20 s, median 3.28 s (pandas `groupby().median()` 5.61 s). What it does **not** do is skip NaN — it propagates, while pycytominer's pandas-based median skips. So `aggregate` checks for NaN once and takes the scanpy path when the matrix is clean (the common case after `filter_features` / `drop_na_columns`), falling back to our NaN-skipping numba kernel otherwise. Both paths are covered by the same tests, including the pycytominer equivalence test, which is run with and without injected NaN.
2. **`normalize(keep_raw=...)` defaults to `False`,** not `True`. Storing `layers["raw"]` doubles memory and consumes the whole 0.5 benchmark budget by itself; the raw table is already on disk.
3. **`epsilon` default is `1e-18`,** matching pycytominer's `mad_robustize_epsilon`, so equivalence holds without the caller passing anything.
4. **`_core/_chunks.py` exists from 0.1** so that backed/streaming support at 0.5 is a reader feature rather than a rewrite of every reduction.

```python
# src/mantispy/_core/plate.py
"""Plate and well geometry helpers."""

from __future__ import annotations

import re
from collections.abc import Iterable

PLATE_FORMATS: dict[int, tuple[int, int]] = {96: (8, 12), 384: (16, 24), 1536: (32, 48)}

_WELL_RE = re.compile(r"^([A-Za-z]{1,2})[\s_-]?(\d{1,2})$")


def normalize_well(well: str) -> str:
    """Return ``well`` in canonical ``A01`` form."""
    match = _WELL_RE.match(str(well).strip())
    if match is None:
        raise ValueError(f"cannot parse well name: {well!r}")
    row, col = match.group(1).upper(), int(match.group(2))
    if col < 1:
        raise ValueError(f"cannot parse well name: {well!r}")
    return f"{row}{col:02d}"


def well_row(well: str) -> int:
    """0-based row index of ``well`` (``A`` -> 0, ``AA`` -> 26)."""
    letters = normalize_well(well)[:-2]
    value = 0
    for char in letters:
        value = value * 26 + (ord(char) - 64)
    return value - 1


def well_col(well: str) -> int:
    """0-based column index of ``well``."""
    return int(normalize_well(well)[-2:]) - 1


def detect_plate_format(wells: Iterable[str]) -> int:
    """Smallest standard plate format that contains every well in ``wells``."""
    wells = list(wells)
    if not wells:
        raise ValueError("no wells given")
    n_rows = max(well_row(w) for w in wells) + 1
    n_cols = max(well_col(w) for w in wells) + 1
    for size in sorted(PLATE_FORMATS):
        max_rows, max_cols = PLATE_FORMATS[size]
        if n_rows <= max_rows and n_cols <= max_cols:
            return size
    raise ValueError(f"no standard plate format holds {n_rows} rows x {n_cols} columns")
```

```python
# src/mantispy/_core/features.py
"""Parse CellProfiler / cp_measure feature names into structured annotations."""

from __future__ import annotations

import re
from collections import defaultdict
from collections.abc import Sequence
from importlib.resources import files

import numpy as np
import pandas as pd

COLUMNS = [
    "object", "feature_group", "feature", "channel",
    "scale", "angle", "gray_levels", "radial_bin", "is_feature",
]

#: Groups that never carry measurements usable as profile features.
NON_FEATURE_GROUPS = frozenset({
    "Number", "Location", "Parent", "Children", "Metadata", "Group", "Count",
    "FileName", "PathName", "URL", "Series", "Frame", "Scaling", "MD5Digest",
    "ExecutionTime", "ModuleError", "Width", "Height", "Threshold",
})

#: Groups whose names contain one or more channel tokens.
CHANNEL_BEARING_GROUPS = frozenset({
    "Intensity", "Texture", "Granularity", "RadialDistribution", "Correlation",
    "ImageQuality", "IntensityDistribution", "Colocalization",
})

#: Bare column names emitted by CellProfiler that are never features.
_BARE_NON_FEATURES = frozenset({
    "ImageNumber", "ObjectNumber", "TableNumber", "Number_Object_Number",
})

_RADIAL_BIN_RE = re.compile(r"^\d+of\d+$")
_NUMERIC_RE = re.compile(r"^-?\d+(\.\d+)?$")


def _is_numeric(token: str) -> bool:
    return bool(_NUMERIC_RE.match(token))


def _infer_channels(names: Sequence[str]) -> list[str]:
    """Guess the channel vocabulary from a list of names.

    A token is treated as a channel when it appears in a channel-bearing group,
    is not numeric, is not a radial bin, and occurs with at least two distinct
    feature names within its group.
    """
    seen: dict[str, set[str]] = defaultdict(set)
    for name in names:
        tokens = str(name).split("_")
        for i, token in enumerate(tokens):
            if token in CHANNEL_BEARING_GROUPS and i + 2 < len(tokens):
                for candidate in tokens[i + 2:]:
                    if not _is_numeric(candidate) and not _RADIAL_BIN_RE.match(candidate):
                        seen[candidate].add(tokens[i + 1])
    return sorted(token for token, features in seen.items() if len(features) >= 2)


def _parse_one(name: str, channels: frozenset[str]) -> dict:
    empty = dict.fromkeys(COLUMNS)
    empty["is_feature"] = False

    tokens = str(name).split("_")
    if name in _BARE_NON_FEATURES or len(tokens) < 2:
        return empty

    # An object prefix is present when the *second* token looks like a group.
    if tokens[0] in NON_FEATURE_GROUPS or tokens[0] in CHANNEL_BEARING_GROUPS:
        obj, group, rest = None, tokens[0], tokens[1:]
    elif tokens[0] == "Image":
        obj, group, rest = "Image", tokens[1], tokens[2:]
    elif len(tokens) >= 3:
        obj, group, rest = tokens[0], tokens[1], tokens[2:]
    else:
        obj, group, rest = None, tokens[0], tokens[1:]

    row = dict(empty)
    row["object"] = obj
    row["feature_group"] = group

    if group in NON_FEATURE_GROUPS or not rest:
        return row

    # Peel channel tokens off the tail.
    found_channels = [token for token in rest if token in channels]
    rest = [token for token in rest if token not in channels]
    if found_channels:
        row["channel"] = "|".join(found_channels)

    # Peel structured trailing parameters.
    radial = [token for token in rest if _RADIAL_BIN_RE.match(token)]
    if radial:
        row["radial_bin"] = radial[0]
        rest = [token for token in rest if token not in radial]

    numeric = [token for token in rest if _is_numeric(token)]
    rest = [token for token in rest if not _is_numeric(token)]
    if group == "Texture":
        for key, value in zip(("scale", "angle", "gray_levels"), numeric, strict=False):
            row[key] = float(value)
    elif numeric:
        row["scale"] = float(numeric[0])

    row["feature"] = "_".join(rest) if rest else group
    row["is_feature"] = True
    return row


def parse_feature_names(
    names: Sequence[str], channels: Sequence[str] | None = None
) -> pd.DataFrame:
    """Parse ``names`` into a table of feature annotations indexed by name."""
    names = list(names)
    channel_set = frozenset(channels if channels is not None else _infer_channels(names))
    parsed = pd.DataFrame(
        [_parse_one(name, channel_set) for name in names], index=pd.Index(names, name=None)
    )
    parsed = parsed[COLUMNS]
    for column in ("scale", "angle", "gray_levels"):
        parsed[column] = parsed[column].astype("float64")
    parsed["is_feature"] = parsed["is_feature"].astype(bool)
    for column in ("object", "feature_group", "feature", "channel", "radial_bin"):
        parsed[column] = parsed[column].astype("object").where(parsed[column].notna(), np.nan)
    return parsed


def load_blocklist(name: str = "default") -> list[str]:
    """Return the list of feature names blocked by default."""
    if name != "default":
        raise ValueError(f"unknown blocklist: {name!r}")
    text = (files("mantispy._core.data") / "blocklist_cellprofiler.txt").read_text()
```

```python
# src/mantispy/_core/schema.py
"""The mantispy AnnData contract."""

from __future__ import annotations

from dataclasses import dataclass, field

import numpy as np
from anndata import AnnData

from .features import COLUMNS as VAR_COLUMNS
from .plate import normalize_well

SCHEMA_VERSION = "0.1"

REQUIRED_OBS: tuple[str, ...] = ("Metadata_Plate", "Metadata_Well")
RESERVED_OBS: tuple[str, ...] = (
    "Metadata_Batch", "Metadata_Source", "Metadata_Site", "Metadata_ImageNumber",
    "Metadata_Perturbation", "Metadata_Compound", "Metadata_Concentration",
    "Metadata_MOA", "Metadata_Control", "Metadata_CellCount",
    # reserved for optical pooled screening, unused before 0.8
    "Metadata_Barcode", "Metadata_Gene", "Metadata_sgRNA", "Metadata_BarcodeQuality",
)
REQUIRED_VAR: tuple[str, ...] = tuple(VAR_COLUMNS)
RESOLUTIONS = ("cell", "well", "perturbation")


@dataclass
class ValidationReport:
    """Result of :func:`validate`."""

    errors: list[str] = field(default_factory=list)
    warnings: list[str] = field(default_factory=list)

    @property
    def ok(self) -> bool:
        return not self.errors

    def __bool__(self) -> bool:
        return self.ok

    def __str__(self) -> str:
        lines = [f"ERROR: {e}" for e in self.errors] + [f"WARNING: {w}" for w in self.warnings]
        return "\n".join(lines) or "valid"


def stamp(adata: AnnData) -> None:
    """Write the current schema version into ``adata.uns``."""
    adata.uns.setdefault("mantispy", {})["schema_version"] = SCHEMA_VERSION


def validate(adata: AnnData, *, raise_on_error: bool = False) -> ValidationReport:
    """Check ``adata`` against the mantispy schema."""
    report = ValidationReport()

    for column in REQUIRED_OBS:
        if column not in adata.obs:
            report.errors.append(f"obs is missing required column {column!r}")

    for column in REQUIRED_VAR:
        if column not in adata.var:
            report.errors.append(f"var is missing required column {column!r}")

    meta = adata.uns.get("mantispy")
    if not isinstance(meta, dict) or "schema_version" not in meta:
        report.errors.append("uns['mantispy']['schema_version'] is missing")
    elif meta["schema_version"] != SCHEMA_VERSION:
        report.errors.append(
            f"schema_version {meta['schema_version']!r} != supported {SCHEMA_VERSION!r}"
        )
    elif meta.get("resolution") not in (None, *RESOLUTIONS):
        report.warnings.append(f"unknown resolution {meta.get('resolution')!r}")

    if adata.X is not None and getattr(adata.X, "dtype", None) != np.float32:
        report.errors.append(f"X must be float32, got {getattr(adata.X, 'dtype', None)}")

    if "Metadata_Well" in adata.obs:
        bad = []
        for well in adata.obs["Metadata_Well"].astype(str).unique():
            try:
                normalize_well(well)
            except ValueError:
                bad.append(well)
        if bad:
            report.errors.append(f"Metadata_Well has unparsable values: {sorted(bad)[:5]}")

    if adata.n_vars and "is_feature" in adata.var and not adata.var["is_feature"].any():
        report.warnings.append("no column in var is marked is_feature")

    if raise_on_error and not report.ok:
        raise ValueError("\n".join(report.errors))
    return report
```

```python
# src/mantispy/_core/_utils.py
"""Small shared helpers."""

from __future__ import annotations

import json
import logging
import warnings

import numpy as np
from anndata import AnnData

_LOGGER = logging.getLogger("mantispy")


def get_logger() -> logging.Logger:
    """Return the package logger."""
    return _LOGGER


def maybe_copy(adata: AnnData, copy: bool) -> AnnData:
    """Return ``adata.copy()`` when ``copy`` else ``adata``."""
    return adata.copy() if copy else adata


def _jsonable(value):
    if isinstance(value, np.ndarray):
        return value.tolist()
    if isinstance(value, np.generic):
        return value.item()
    try:
        json.dumps(value)
    except (TypeError, ValueError):
        return repr(value)
    return value


def record_params(adata: AnnData, func_name: str, params: dict) -> None:
    """Record a call's parameters under ``uns['mantispy']['params'][func_name]``."""
    store = adata.uns.setdefault("mantispy", {}).setdefault("params", {})
    store[func_name] = {key: _jsonable(value) for key, value in params.items()}


def warn_resolution(adata: AnnData, expected: str) -> None:
    """Warn (never raise) when the recorded resolution is not ``expected``."""
    actual = adata.uns.get("mantispy", {}).get("resolution")
    if actual is not None and actual != expected:
        warnings.warn(
            f"this function expects resolution {expected!r} but the object is "
            f"annotated {actual!r}; results may not be meaningful",
            UserWarning,
            stacklevel=3,
        )
```

```python
# src/mantispy/datasets/_synthetic.py
"""Synthetic plate with known ground truth."""

from __future__ import annotations

import anndata as ad
import numpy as np
import pandas as pd

from .._core.features import parse_feature_names
from .._core.plate import PLATE_FORMATS, well_col, well_row
from .._core.schema import stamp

CHANNELS = ("DNA", "ER", "RNA", "AGP", "Mito")
_OBJECTS = ("Cells", "Nuclei", "Cytoplasm")
_SHAPE_FEATURES = ("Area", "Perimeter", "Eccentricity", "FormFactor", "Solidity")
_INTENSITY_FEATURES = ("MeanIntensity", "MaxIntensity", "IntegratedIntensity", "StdIntensity")
_TEXTURE_FEATURES = ("Contrast", "Correlation", "Entropy", "Variance")


def _feature_names(n_features: int) -> list[str]:
    names: list[str] = []
    for obj in _OBJECTS:
        for feature in _SHAPE_FEATURES:
            names.append(f"{obj}_AreaShape_{feature}")
        for channel in CHANNELS:
            for feature in _INTENSITY_FEATURES:
                names.append(f"{obj}_Intensity_{feature}_{channel}")
            for feature in _TEXTURE_FEATURES:
                names.append(f"{obj}_Texture_{feature}_{channel}_3_00_256")
    if len(names) < n_features:
        raise ValueError(f"cannot generate {n_features} distinct names (max {len(names)})")
    return names[:n_features]


def _wells(n_wells: int) -> list[str]:
    size = next(s for s in sorted(PLATE_FORMATS) if s >= n_wells)
    n_rows, n_cols = PLATE_FORMATS[size]
    wells = [f"{chr(65 + r)}{c + 1:02d}" for r in range(n_rows) for c in range(n_cols)]
    return wells[:n_wells]


def synthetic_plate(
    n_plates: int = 1,
    n_wells: int = 384,
    n_cells: int = 200,
    n_features: int = 60,
    n_perturbations: int = 8,
    effect_size: float = 1.0,
    plate_effect: float = 0.0,
    row_gradient: float = 0.0,
    col_gradient: float = 0.0,
    nan_fraction: float = 0.0,
    seed: int = 0,
) -> ad.AnnData:
    """Generate a synthetic plate whose injected effects are recorded in ``uns``."""
    rng = np.random.default_rng(seed)
    names = _feature_names(n_features)
    wells = _wells(n_wells)

    perturbations = ["DMSO"] + [f"pert{i:02d}" for i in range(n_perturbations)]
    well_pert = [perturbations[i % len(perturbations)] for i in range(n_wells)]

    affected = {
        pert: sorted(rng.choice(names, size=max(1, n_features // 5), replace=False).tolist())
        for pert in perturbations
        if pert != "DMSO"
    }
    affected["DMSO"] = []

    obs_rows, blocks = [], []
    for plate_i in range(n_plates):
        plate = f"Plate{plate_i + 1:02d}"
        for well_i, well in enumerate(wells):
            pert = well_pert[well_i]
            block = rng.standard_normal((n_cells, n_features)).astype(np.float64)
            block += plate_effect * plate_i
            block += row_gradient * (well_row(well) / 8.0)
            block += col_gradient * (well_col(well) / 12.0)
            if affected[pert]:
                idx = [names.index(name) for name in affected[pert]]
                block[:, idx] += effect_size
            blocks.append(block)
            obs_rows.extend(
                {
                    "Metadata_Plate": plate,
                    "Metadata_Well": well,
                    "Metadata_Row": well_row(well),
                    "Metadata_Col": well_col(well),
                    "Metadata_Perturbation": pert,
                    "Metadata_Control": pert == "DMSO",
                    "Metadata_Batch": f"Batch{plate_i // 2 + 1}",
                    "Metadata_ImageNumber": plate_i * n_wells + well_i,
                }
                for _ in range(n_cells)
            )

    X = np.vstack(blocks).astype(np.float32)
    if nan_fraction > 0:
        mask = rng.random(X.shape) < nan_fraction
        X[mask] = np.nan

    obs = pd.DataFrame(obs_rows)
    obs.index = pd.Index([f"cell_{i}" for i in range(len(obs))], name=None)
    adata = ad.AnnData(X=X, obs=obs, var=parse_feature_names(names, channels=CHANNELS))
    stamp(adata)
    adata.uns["mantispy"]["resolution"] = "cell"
    adata.uns["mantispy"]["truth"] = {
        "affected_features": affected,
        "effect_size": float(effect_size),
        "plate_effect": float(plate_effect),
        "row_gradient": float(row_gradient),
        "col_gradient": float(col_gradient),
    }
    return adata
```

```python
# src/mantispy/_core/_numba.py
"""NaN-aware grouped reduction kernels."""

from __future__ import annotations

import numpy as np
from numba import njit, prange

_JIT = {"cache": True, "fastmath": False, "nogil": True}


def _order_and_offsets(codes: np.ndarray, n_groups: int) -> tuple[np.ndarray, np.ndarray]:
    order = np.argsort(codes, kind="stable").astype(np.int64)
    counts = np.bincount(codes, minlength=n_groups).astype(np.int64)
    offsets = np.zeros(n_groups + 1, dtype=np.int64)
    np.cumsum(counts, out=offsets[1:])
    return order, offsets


def group_counts(codes: np.ndarray, n_groups: int) -> np.ndarray:
    """Number of rows per group."""
    return np.bincount(np.asarray(codes), minlength=n_groups).astype(np.int64)


@njit(**_JIT)
def _gather(Xs, start, stop, j, buf):
    """Copy the non-NaN values of column ``j`` in rows ``[start, stop)`` into ``buf``."""
    n = 0
    for i in range(start, stop):
        value = Xs[i, j]
        if not np.isnan(value):
            buf[n] = value
            n += 1
    return n


@njit(**_JIT)
def _median_of(buf, n):
    if n == 0:
        return np.nan
    part = np.sort(buf[:n])
    mid = n // 2
    if n % 2 == 1:
        return part[mid]
    return 0.5 * (part[mid - 1] + part[mid])


@njit(**_JIT)
def _quantile_of(buf, n, q):
    if n == 0:
        return np.nan
    part = np.sort(buf[:n])
    pos = q * (n - 1)
    lo = int(np.floor(pos))
    hi = int(np.ceil(pos))
    if lo == hi:
        return part[lo]
    return part[lo] + (pos - lo) * (part[hi] - part[lo])


@njit(parallel=True, **_JIT)
def _reduce(Xs, offsets, n_groups, n_vars, kind, q):
    out = np.empty((n_groups, n_vars), dtype=np.float64)
    max_len = 0
    for g in range(n_groups):
        length = offsets[g + 1] - offsets[g]
        if length > max_len:
            max_len = length
    for flat in prange(n_groups * n_vars):
        g = flat // n_vars
        j = flat % n_vars
        start, stop = offsets[g], offsets[g + 1]
        buf = np.empty(max_len, dtype=np.float64)
        n = _gather(Xs, start, stop, j, buf)
        if n == 0:
            out[g, j] = np.nan
        elif kind == 0:  # mean
            total = 0.0
            for k in range(n):
                total += buf[k]
            out[g, j] = total / n
        elif kind == 1:  # median
            out[g, j] = _median_of(buf, n)
        elif kind == 2:  # mad
            med = _median_of(buf, n)
            for k in range(n):
                buf[k] = abs(buf[k] - med)
            out[g, j] = _median_of(buf, n)
        elif kind == 3:  # std, ddof=1
            if n < 2:
                out[g, j] = np.nan
            else:
                total = 0.0
                for k in range(n):
                    total += buf[k]
                mean = total / n
                sq = 0.0
                for k in range(n):
                    sq += (buf[k] - mean) ** 2
                out[g, j] = np.sqrt(sq / (n - 1))
        else:  # quantile
            out[g, j] = _quantile_of(buf, n, q)
    return out


def _dispatch(X, codes, n_groups, kind, q=0.5):
    X = np.asarray(X, dtype=np.float32)
    codes = np.asarray(codes, dtype=np.int32)
    order, offsets = _order_and_offsets(codes, n_groups)
    Xs = np.ascontiguousarray(X[order], dtype=np.float64)
    return _reduce(Xs, offsets, n_groups, X.shape[1], kind, float(q))


def grouped_mean(X, codes, n_groups):
    """Per-group NaN-skipping mean."""
    return _dispatch(X, codes, n_groups, 0)


def grouped_median(X, codes, n_groups):
    """Per-group NaN-skipping median."""
    return _dispatch(X, codes, n_groups, 1)


def grouped_mad(X, codes, n_groups):
    """Per-group raw (unscaled) median absolute deviation."""
    return _dispatch(X, codes, n_groups, 2)


def grouped_std(X, codes, n_groups):
    """Per-group NaN-skipping standard deviation with ``ddof=1``."""
    return _dispatch(X, codes, n_groups, 3)


def grouped_quantile(X, codes, n_groups, q):
    """Per-group NaN-skipping quantile with linear interpolation."""
    return _dispatch(X, codes, n_groups, 4, q)
```

```python
# src/mantispy/_core/_chunks.py
"""The single seam through which grouped operations read the matrix.

Every ``pp``/``tl`` reduction must consume data through :func:`iter_groups` or
:func:`group_codes`, never by indexing ``adata.X`` directly. Backed and chunked
IO (0.5) replaces the body of these functions and nothing else.
"""

from __future__ import annotations

from collections.abc import Iterator, Sequence
from typing import Any

import numpy as np
import pandas as pd
from anndata import AnnData


def get_matrix(adata: AnnData, layer: str | None = None) -> np.ndarray:
    """Return the requested matrix as a dense ``float32`` array."""
    matrix = adata.X if layer is None else adata.layers[layer]
    if hasattr(matrix, "toarray"):
        matrix = matrix.toarray()
    return np.asarray(matrix, dtype=np.float32)


def group_codes(
    adata: AnnData, by: str | Sequence[str] | None
) -> tuple[np.ndarray, pd.Index]:
    """Per-row integer group codes plus the ordered group keys."""
    if by is None:
        return np.zeros(adata.n_obs, dtype=np.int32), pd.Index(["all"])
    columns = [by] if isinstance(by, str) else list(by)
    missing = [c for c in columns if c not in adata.obs]
    if missing:
        raise KeyError(f"obs is missing grouping column(s): {missing}")
    if len(columns) == 1:
        keys = pd.Index(pd.unique(adata.obs[columns[0]]))
        keys = keys.sort_values()
        codes = keys.get_indexer(adata.obs[columns[0]])
    else:
        frame = adata.obs[columns].astype(str)
        tuples = pd.MultiIndex.from_frame(frame)
        keys = tuples.unique().sort_values()
        codes = keys.get_indexer(tuples)
    if (codes < 0).any():
        raise ValueError("grouping column contains values that could not be indexed (NaN?)")
    return codes.astype(np.int32), keys


def iter_groups(
    adata: AnnData, by: str | Sequence[str] | None, layer: str | None = None
) -> Iterator[tuple[Any, np.ndarray, np.ndarray]]:
    """Yield ``(key, row_index, block)`` for each group, in group-key order."""
    codes, keys = group_codes(adata, by)
    matrix = get_matrix(adata, layer)
    order = np.argsort(codes, kind="stable")
    boundaries = np.searchsorted(codes[order], np.arange(len(keys) + 1))
    for g, key in enumerate(keys):
        rows = order[boundaries[g] : boundaries[g + 1]]
        yield key, rows, matrix[rows]
```

```python
_KEYS = ("ImageNumber", "ObjectNumber")


def _infer_channels(image: pd.DataFrame) -> list[str]:
    pattern = re.compile(r"^Image_FileName_(.+)$")
    return sorted(
        {m.group(1) for m in (pattern.match(c) for c in image.columns) if m is not None}
    )


def _prefix(frame: pd.DataFrame, obj: str) -> pd.DataFrame:
    renamed = {
        c: c if c in _KEYS or c.startswith(f"{obj}_") else f"{obj}_{c}" for c in frame.columns
    }
    return frame.rename(columns=renamed)


def _discover_objects(directory: Path, primary: str) -> list[str]:
    found = [p.stem for p in sorted(directory.glob("*.csv")) if p.stem not in {"Image", "Experiment"}]
    if primary not in found:
        raise FileNotFoundError(f"{primary}.csv not found in {directory}")
    return [primary] + [name for name in found if name != primary]


def read_cellprofiler(
    path: str | Path,
    primary_object: str = "Cells",
    objects: Sequence[str] | None = None,
    channels: Sequence[str] | None = None,
    platemap: str | Path | pd.DataFrame | None = None,
    strict_one_to_one: bool = True,
) -> ad.AnnData:
    """Read a CellProfiler ``ExportToSpreadsheet`` CSV directory."""
    directory = Path(path)
    image = pd.read_csv(directory / "Image.csv")
    names = list(objects) if objects else _discover_objects(directory, primary_object)
    if names[0] != primary_object:
        names = [primary_object] + [n for n in names if n != primary_object]

    merged = _prefix(pd.read_csv(directory / f"{primary_object}.csv"), primary_object)
    n_primary = len(merged)

    for obj in names[1:]:
        child = _prefix(pd.read_csv(directory / f"{obj}.csv"), obj)
        parent_col = f"{obj}_Parent_{primary_object}"
        if parent_col in child.columns:
            child = child.rename(columns={parent_col: "ObjectNumber", "ObjectNumber": f"{obj}_ObjectNumber"})
        counts = child.groupby(list(_KEYS), dropna=False).size()
        if strict_one_to_one and (counts != 1).any():
            raise ValueError(
                f"join to {obj!r} is not one-to-one with {primary_object!r}: "
                f"{int((counts != 1).sum())} parents have != 1 child. "
                "Pass strict_one_to_one=False to keep the first match."
            )
        child = child.drop_duplicates(subset=list(_KEYS), keep="first")
        merged = merged.merge(child, on=list(_KEYS), how="left", validate="one_to_one")

    if len(merged) != n_primary:
        raise ValueError("object join changed the row count; this is a bug")

    image_qc = image[["ImageNumber"] + [c for c in image.columns if "ImageQuality" in c]]
    image_qc = image_qc.set_index("ImageNumber")

    meta_cols = {c: "Metadata_" + c.removeprefix("Image_Metadata_") for c in image.columns if c.startswith("Image_Metadata_")}
    obs_source = image[["ImageNumber", *meta_cols]].rename(columns=meta_cols)
    merged = merged.merge(obs_source, on="ImageNumber", how="left")

    obs = merged[[c for c in merged.columns if c.startswith("Metadata_")]].copy()
    obs["Metadata_ImageNumber"] = merged["ImageNumber"].to_numpy()
    obs["Metadata_ObjectNumber"] = merged["ObjectNumber"].to_numpy()
    if "Metadata_Well" in obs:
        obs["Metadata_Well"] = [normalize_well(w) for w in obs["Metadata_Well"].astype(str)]

    if platemap is not None:
        plate_frame = platemap if isinstance(platemap, pd.DataFrame) else pd.read_csv(platemap)
        if "Metadata_Well" not in plate_frame:
            raise ValueError("platemap must contain a 'Metadata_Well' column")
        plate_frame = plate_frame.copy()
        plate_frame["Metadata_Well"] = [
            normalize_well(w) for w in plate_frame["Metadata_Well"].astype(str)
        ]
        on = ["Metadata_Well"] + (["Metadata_Plate"] if "Metadata_Plate" in plate_frame else [])
        obs = obs.merge(plate_frame, on=on, how="left", suffixes=("", "_platemap"))

    channels = list(channels) if channels else _infer_channels(image)
    candidates = [c for c in merged.columns if c not in _KEYS and not c.startswith("Metadata_")]
    parsed = parse_feature_names(candidates, channels=channels)
    feature_names = parsed.index[parsed["is_feature"]].tolist()

    X = merged[feature_names].to_numpy(dtype=np.float32)
    obs.index = pd.Index([str(i) for i in range(len(obs))], name=None)
    adata = ad.AnnData(X=X, obs=obs, var=parsed.loc[feature_names])

    stamp(adata)
    adata.uns["mantispy"]["resolution"] = "cell"
    adata.uns["mantispy"]["channels"] = channels
    adata.uns["mantispy"]["image_table"] = image_qc
    record_params(
        adata,
        "read_cellprofiler",
        {
            "path": str(directory),
            "primary_object": primary_object,
            "objects": names,
            "channels": channels,
            "strict_one_to_one": strict_one_to_one,
        },
    )
    get_logger().info("read %d cells x %d features from %s", adata.n_obs, adata.n_vars, directory)
    return adata
```

```python
"""Generic profile IO."""

from __future__ import annotations

from collections.abc import Sequence
from pathlib import Path

import anndata as ad
import numpy as np
import pandas as pd

from .._core.features import parse_feature_names
from .._core.plate import normalize_well
from .._core.schema import SCHEMA_VERSION, stamp, validate


def from_dataframe(
    df: pd.DataFrame,
    metadata_prefix: str = "Metadata_",
    channels: Sequence[str] | None = None,
    resolution: str = "cell",
) -> ad.AnnData:
    """Build an AnnData from a wide profile table."""
    obs_cols = [c for c in df.columns if c.startswith(metadata_prefix)]
    candidates = [c for c in df.columns if c not in obs_cols]
    parsed = parse_feature_names(candidates, channels=channels)
    feature_names = parsed.index[parsed["is_feature"]].tolist()

    obs = df[obs_cols].reset_index(drop=True)
    if "Metadata_Well" in obs:
        obs["Metadata_Well"] = [normalize_well(w) for w in obs["Metadata_Well"].astype(str)]
    obs.index = pd.Index([str(i) for i in range(len(obs))], name=None)

    adata = ad.AnnData(
        X=df[feature_names].to_numpy(dtype=np.float32),
        obs=obs,
        var=parsed.loc[feature_names],
    )
    stamp(adata)
    adata.uns["mantispy"]["resolution"] = resolution
    return adata


def read_profiles(path: str | Path, **kwargs) -> ad.AnnData:
    """Read a pycytominer-style profile table (csv / tsv / parquet)."""
    path = Path(path)
    if path.suffix in {".parquet", ".pq"}:
        frame = pd.read_parquet(path)
    elif path.suffix in {".tsv", ".txt"}:
        frame = pd.read_csv(path, sep="\t")
    else:
        frame = pd.read_csv(path)
    return from_dataframe(frame, **kwargs)


def read(path: str | Path) -> ad.AnnData:
    """Read a mantispy h5ad or zarr store and check its schema version."""
    path = Path(path)
    adata = ad.read_zarr(path) if path.suffix == ".zarr" else ad.read_h5ad(path)
    stored = adata.uns.get("mantispy", {}).get("schema_version")
    if stored != SCHEMA_VERSION:
        raise ValueError(
            f"file was written with schema_version {stored!r}, this version supports "
            f"{SCHEMA_VERSION!r}"
        )
    return adata


def write(adata: ad.AnnData, path: str | Path) -> None:
    """Validate, stamp and write ``adata`` as h5ad (default) or zarr."""
    path = Path(path)
    stamp(adata)
    validate(adata, raise_on_error=True)
    if path.suffix == ".zarr":
        adata.write_zarr(path)
    else:
        adata.write_h5ad(path)
```

```python
# src/mantispy/pp/_qc.py
"""Basic quality control metrics and filters."""

from __future__ import annotations

from collections.abc import Sequence

import numpy as np
from anndata import AnnData

from .._core._chunks import get_matrix, group_codes
from .._core._numba import grouped_mad, grouped_median
from .._core._utils import maybe_copy, record_params
from .._core.features import load_blocklist


def calculate_qc_metrics(
    adata: AnnData,
    image_shape: tuple[int, int] | None = None,
    border_margin: int = 10,
    copy: bool = False,
) -> AnnData | None:
    """Compute per-cell and per-feature QC metrics."""
    adata = maybe_copy(adata, copy)
    X = get_matrix(adata)
    nan_mask = np.isnan(X)

    adata.obs["qc_n_nan_features"] = nan_mask.sum(axis=1).astype(np.int32)
    adata.var["qc_n_nan"] = nan_mask.sum(axis=0).astype(np.int32)
    adata.var["qc_variance"] = np.nanvar(X, axis=0)
    adata.var["qc_n_unique"] = np.array(
        [len(np.unique(X[~nan_mask[:, j], j])) for j in range(X.shape[1])], dtype=np.int32
    )

    border = np.zeros(adata.n_obs, dtype=bool)
    have_coords = {"Metadata_Center_X", "Metadata_Center_Y"} <= set(adata.obs.columns)
    if image_shape is not None and have_coords:
        height, width = image_shape
        x = adata.obs["Metadata_Center_X"].to_numpy(dtype=float)
        y = adata.obs["Metadata_Center_Y"].to_numpy(dtype=float)
        border = (
            (x < border_margin)
            | (y < border_margin)
            | (x > width - border_margin)
            | (y > height - border_margin)
        )
    adata.obs["qc_is_border"] = border

    area_outlier = np.zeros(adata.n_obs, dtype=bool)
    area_cols = adata.var_names[adata.var["feature"].astype(str).eq("Area")]
    if len(area_cols) and "Metadata_Plate" in adata.obs:
        column = X[:, adata.var_names.get_loc(area_cols[0])][:, None]
        codes, keys = group_codes(adata, "Metadata_Plate")
        median = grouped_median(column, codes, len(keys))[codes, 0]
        mad = grouped_mad(column, codes, len(keys))[codes, 0] * 1.4826
        with np.errstate(invalid="ignore", divide="ignore"):
            z = np.abs(column[:, 0] - median) / mad
        area_outlier = np.nan_to_num(z, nan=0.0) > 5.0
    adata.obs["qc_area_outlier"] = area_outlier

    adata.obs["qc_pass"] = (
        ~adata.obs["qc_is_border"].to_numpy()
        & ~adata.obs["qc_area_outlier"].to_numpy()
        & (adata.obs["qc_n_nan_features"].to_numpy() == 0)
    )
    record_params(
        adata, "calculate_qc_metrics", {"image_shape": image_shape, "border_margin": border_margin}
    )
    return adata if copy else None


def filter_cells(
    adata: AnnData, min_cells_per_well: int = 50, qc_pass: bool = True, copy: bool = False
) -> AnnData | None:
    """Drop cells that fail QC or sit in under-populated wells."""
    keep = np.ones(adata.n_obs, dtype=bool)
    if qc_pass:
        if "qc_pass" not in adata.obs:
            raise KeyError("run ms.pp.calculate_qc_metrics first, or pass qc_pass=False")
        keep &= adata.obs["qc_pass"].to_numpy(dtype=bool)
    if min_cells_per_well > 0:
        codes, keys = group_codes(adata, ["Metadata_Plate", "Metadata_Well"])
        counts = np.bincount(codes, minlength=len(keys))
        keep &= counts[codes] >= min_cells_per_well

    result = adata[keep].copy()
    record_params(
        result, "filter_cells", {"min_cells_per_well": min_cells_per_well, "qc_pass": qc_pass}
    )
    if copy:
        return result
    adata._init_as_actual(result)
    return None


def filter_features(
    adata: AnnData,
    drop_nan: bool = True,
    min_variance: float = 0.0,
    blocklist: str | Sequence[str] | None = "default",
    copy: bool = False,
) -> AnnData | None:
    """Drop all-NaN, low-variance and blocklisted features."""
    X = get_matrix(adata)
    keep = np.ones(adata.n_vars, dtype=bool)
    if drop_nan:
        keep &= ~np.isnan(X).all(axis=0)
    if min_variance > 0:
        with np.errstate(invalid="ignore"):
            keep &= np.nan_to_num(np.nanvar(X, axis=0), nan=0.0) >= min_variance
    if blocklist is not None:
        blocked = set(load_blocklist() if blocklist == "default" else blocklist)
        keep &= ~adata.var_names.isin(blocked)

    result = adata[:, keep].copy()
    record_params(
        result,
        "filter_features",
        {"drop_nan": drop_nan, "min_variance": min_variance, "blocklist": str(blocklist)},
    )
    if copy:
        return result
    adata._init_as_actual(result)
    return None
```

```python
# src/mantispy/pp/_normalize.py
"""Per-group normalization."""

from __future__ import annotations

import numpy as np
from anndata import AnnData

from .._core._chunks import get_matrix, group_codes
from .._core._numba import (
    grouped_mad,
    grouped_mean,
    grouped_median,
    grouped_quantile,
    grouped_std,
)
from .._core._utils import maybe_copy, record_params

METHODS = ("mad_robustize", "standardize", "robustize")


def _reference_mask(adata: AnnData, reference: str | None) -> np.ndarray:
    if reference is None:
        return np.ones(adata.n_obs, dtype=bool)
    column = "Metadata_Control" if reference == "negcon" else reference
    if column not in adata.obs:
        raise KeyError(f"obs has no column {column!r} to use as reference")
    return adata.obs[column].to_numpy(dtype=bool)


def normalize(
    adata: AnnData,
    method: str = "mad_robustize",
    by: str | list[str] | None = "Metadata_Plate",
    reference: str | None = None,
    epsilon: float = 1e-18,
    keep_raw: bool = False,
    layer: str | None = None,
    key_added: str | None = None,
    copy: bool = False,
) -> AnnData | None:
    """Normalize features within groups, optionally fitting on reference rows only."""
    if method not in METHODS:
        raise ValueError(f"method must be one of {METHODS}, got {method!r}")
    adata = maybe_copy(adata, copy)

    X = get_matrix(adata, layer)
    codes, keys = group_codes(adata, by)
    n_groups = len(keys)

    mask = _reference_mask(adata, reference)
    if not mask.any():
        raise ValueError(f"no reference rows selected by reference={reference!r}")
    ref_codes, ref_X = codes[mask], X[mask]
    present = np.bincount(ref_codes, minlength=n_groups)
    if (present == 0).any():
        empty = [str(keys[g]) for g in np.flatnonzero(present == 0)]
        raise ValueError(f"no reference rows in group(s): {empty[:5]}")

    if method == "standardize":
        center = grouped_mean(ref_X, ref_codes, n_groups)
        scale = grouped_std(ref_X, ref_codes, n_groups)
    elif method == "mad_robustize":
        center = grouped_median(ref_X, ref_codes, n_groups)
        scale = 1.4826 * grouped_mad(ref_X, ref_codes, n_groups) + epsilon
    else:  # robustize
        center = grouped_median(ref_X, ref_codes, n_groups)
        scale = grouped_quantile(ref_X, ref_codes, n_groups, 0.75) - grouped_quantile(
            ref_X, ref_codes, n_groups, 0.25
        )

    with np.errstate(invalid="ignore", divide="ignore"):
        out = ((X - center[codes]) / scale[codes]).astype(np.float32)

    if keep_raw and "raw" not in adata.layers:
        adata.layers["raw"] = X.copy()
    if key_added is None:
        adata.X = out
    else:
        adata.layers[key_added] = out

    record_params(
        adata,
        "normalize",
        {
            "method": method, "by": by, "reference": reference, "epsilon": epsilon,
            "keep_raw": keep_raw, "layer": layer, "key_added": key_added,
        },
    )
    return adata if copy else None
```

```python
# src/mantispy/tl/_aggregate.py
"""Aggregate single cells to well- or perturbation-level profiles."""

from __future__ import annotations

from collections.abc import Sequence

import anndata as ad
import numpy as np
import pandas as pd
import scanpy as sc
from anndata import AnnData

from .._core._chunks import get_matrix, group_codes
from .._core._numba import group_counts, grouped_mean, grouped_median
from .._core._utils import get_logger, record_params
from .._core.schema import stamp

_FUNCS = {"median": grouped_median, "mean": grouped_mean}
_WELL_KEYS = {"Metadata_Plate", "Metadata_Well"}


def aggregate(
    adata: AnnData,
    by: Sequence[str] = ("Metadata_Plate", "Metadata_Well"),
    func: str = "median",
    min_cells: int = 10,
    layer: str | None = None,
) -> AnnData:
    """Aggregate ``adata`` to one profile per group."""
    if func not in _FUNCS:
        raise ValueError(f"func must be one of {tuple(_FUNCS)}, got {func!r}")
    by = [by] if isinstance(by, str) else list(by)

    codes, keys = group_codes(adata, by)
    n_groups = len(keys)
    X = get_matrix(adata, layer)
    counts = group_counts(codes, n_groups)

    if not np.isnan(X).any():
        # Fast path: scanpy's kernel, which is well optimized but NaN-propagating.
        # Reorder its rows onto our group-key order so both paths are interchangeable.
        aggregated = sc.get.aggregate(adata, by=by, func=func, layer=layer)
        index = (
            pd.MultiIndex.from_frame(aggregated.obs[by].astype(str))
            if len(by) > 1
            else pd.Index(aggregated.obs[by[0]])
        )
        values = np.asarray(aggregated.layers[func], dtype=np.float32)[index.get_indexer(keys)]
    else:
        values = _FUNCS[func](X, codes, n_groups).astype(np.float32)

    obs = pd.DataFrame(
        {name: keys.get_level_values(i) if n_groups and len(by) > 1 else keys
         for i, name in enumerate(by)}
    ) if len(by) > 1 else pd.DataFrame({by[0]: keys})
    obs = obs.reset_index(drop=True)
    obs["Metadata_CellCount"] = counts

    frame = adata.obs
    for column in frame.columns:
        if column in by or not column.startswith("Metadata_") or column == "Metadata_CellCount":
            continue
        n_unique = frame.groupby(codes, observed=True)[column].nunique(dropna=False)
        if (n_unique <= 1).all():
            obs[column] = frame.groupby(codes, observed=True)[column].first().to_numpy()
        else:
            get_logger().debug("dropping non-constant metadata column %s", column)

    keep = counts >= min_cells
    obs = obs.loc[keep].reset_index(drop=True)
    obs.index = pd.Index([str(i) for i in range(len(obs))], name=None)

    result = ad.AnnData(X=values[keep], obs=obs, var=adata.var.copy())
    stamp(result)
    result.uns["mantispy"]["resolution"] = "well" if set(by) == _WELL_KEYS else "perturbation"
    result.uns["mantispy"]["aggregated_from"] = {
        "by": by, "func": func, "n_obs": int(adata.n_obs), "min_cells": int(min_cells),
    }
    for key in ("channels",):
        if key in adata.uns.get("mantispy", {}):
            result.uns["mantispy"][key] = adata.uns["mantispy"][key]
    record_params(result, "aggregate", {"by": by, "func": func, "min_cells": min_cells})
    return result
```

```python
# src/mantispy/get/__init__.py
"""Accessors that turn a mantispy AnnData into plain Python objects."""

from __future__ import annotations

import numpy as np
import pandas as pd
from anndata import AnnData
from scanpy.get import obs_df, var_df

from .._core._chunks import get_matrix

__all__ = ["controls", "features", "obs_df", "to_dataframe", "var_df"]


def features(
    adata: AnnData,
    object: str | None = None,
    feature_group: str | None = None,
    channel: str | None = None,
    key: str | None = None,
) -> list[str]:
    """Names of features matching every filter given."""
    mask = np.ones(adata.n_vars, dtype=bool)
    if object is not None:
        mask &= (adata.var["object"] == object).to_numpy()
    if feature_group is not None:
        mask &= (adata.var["feature_group"] == feature_group).to_numpy()
    if channel is not None:
        mask &= np.array(
            [channel in str(value).split("|") for value in adata.var["channel"]], dtype=bool
        )
    if key is not None:
        mask &= adata.var[key].to_numpy(dtype=bool)
    return adata.var_names[mask].tolist()


def to_dataframe(adata: AnnData, layer: str | None = None, metadata: bool = True) -> pd.DataFrame:
    """Wide pycytominer-shaped frame: metadata columns first, then features."""
    values = pd.DataFrame(get_matrix(adata, layer), index=adata.obs_names, columns=adata.var_names)
    if not metadata:
        return values
    meta_cols = [c for c in adata.obs.columns if c.startswith("Metadata_")]
    return pd.concat([adata.obs[meta_cols], values], axis=1)


def controls(adata: AnnData, kind: str = "negcon") -> np.ndarray:
    """Boolean mask of control wells or cells."""
    if kind == "negcon":
        if "Metadata_Control" not in adata.obs:
            raise KeyError("obs has no 'Metadata_Control' column")
        return adata.obs["Metadata_Control"].to_numpy(dtype=bool)
    if kind == "poscon":
        if "Metadata_Control_Type" not in adata.obs:
            return np.zeros(adata.n_obs, dtype=bool)
        return (adata.obs["Metadata_Control_Type"] == "poscon").to_numpy(dtype=bool)
    raise ValueError(f"kind must be 'negcon' or 'poscon', got {kind!r}")
```

```python
# src/mantispy/pl/_plate.py
"""Plate-layout plots."""

from __future__ import annotations

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from anndata import AnnData

from .._core._chunks import get_matrix
from .._core.plate import PLATE_FORMATS, detect_plate_format, well_col, well_row

_AGGS = {"median": np.nanmedian, "mean": np.nanmean, "max": np.nanmax, "min": np.nanmin}


def _values(adata: AnnData, color: str) -> np.ndarray:
    if color in adata.var_names:
        return get_matrix(adata)[:, adata.var_names.get_loc(color)].astype(float)
    if color in adata.obs:
        return adata.obs[color].to_numpy(dtype=float)
    raise KeyError(f"{color!r} is neither a feature name nor an obs column")


def plate(
    adata: AnnData,
    color: str,
    plate: str | None = None,
    agg: str = "median",
    ax: plt.Axes | None = None,
    cmap: str = "viridis",
    **kwargs,
):
    """Well-grid heatmap of ``color``, one panel per plate."""
    if agg not in _AGGS:
        raise ValueError(f"agg must be one of {tuple(_AGGS)}, got {agg!r}")
    values = _values(adata, color)

    plates = [plate] if plate is not None else sorted(adata.obs["Metadata_Plate"].unique())
    if ax is None:
        fig, axes = plt.subplots(1, len(plates), figsize=(5 * len(plates), 4), squeeze=False)
        axes = axes.ravel()
    else:
        axes = np.array([ax])
        if len(plates) > 1:
            raise ValueError("pass plate= when supplying a single ax")

    size = detect_plate_format(adata.obs["Metadata_Well"].unique())
    n_rows, n_cols = PLATE_FORMATS[size]

    for axis, name in zip(axes, plates, strict=True):
        mask = (adata.obs["Metadata_Plate"] == name).to_numpy()
        frame = pd.DataFrame(
            {
                "row": [well_row(w) for w in adata.obs["Metadata_Well"][mask]],
                "col": [well_col(w) for w in adata.obs["Metadata_Well"][mask]],
                "value": values[mask],
            }
        )
        grid = np.full((n_rows, n_cols), np.nan)
        for (row, col), block in frame.groupby(["row", "col"]):
            grid[row, col] = _AGGS[agg](block["value"])
        image = axis.imshow(grid, cmap=cmap, aspect="equal", **kwargs)
        axis.set_title(f"{name}\n{color}", fontsize=9)
        axis.set_xticks(range(0, n_cols, max(1, n_cols // 12)))
        axis.set_xticklabels([str(c + 1) for c in range(0, n_cols, max(1, n_cols // 12))], fontsize=7)
        axis.set_yticks(range(n_rows))
        axis.set_yticklabels([chr(65 + r) for r in range(n_rows)], fontsize=7)
        axis.figure.colorbar(image, ax=axis, fraction=0.04)

    return axes[0] if len(axes) == 1 else axes
```

```python
# src/mantispy/pl/_qc.py
"""Quality-control plots."""

from __future__ import annotations

from collections.abc import Sequence

import matplotlib.pyplot as plt
import numpy as np
from anndata import AnnData

from .._core._chunks import get_matrix, group_codes


def cell_counts(adata: AnnData, groupby: str = "Metadata_Plate", ax: plt.Axes | None = None):
    """Distribution of cells per well, split by ``groupby``."""
    ax = ax or plt.subplots(figsize=(6, 4))[1]
    codes, keys = group_codes(adata, ["Metadata_Plate", "Metadata_Well"])
    counts = np.bincount(codes, minlength=len(keys))
    labels = adata.obs.groupby(codes, observed=True)[groupby].first()
    data = [counts[labels.to_numpy() == value] for value in labels.unique()]
    ax.boxplot(data, tick_labels=list(labels.unique()))
    ax.set_ylabel("cells per well")
    ax.set_xlabel(groupby)
    ax.tick_params(axis="x", rotation=45)
    return ax


def feature_distributions(
    adata: AnnData,
    features: Sequence[str],
    groupby: str = "Metadata_Plate",
    layer_before: str | None = "raw",
    kind: str = "ecdf",
    ax=None,
):
    """Per-feature distributions before and after normalization."""
    if kind not in {"ecdf", "kde"}:
        raise ValueError(f"kind must be 'ecdf' or 'kde', got {kind!r}")
    show_before = layer_before is not None and layer_before in adata.layers
    n_rows = 2 if show_before else 1
    fig, axes = plt.subplots(
        n_rows, len(features), figsize=(4 * len(features), 3 * n_rows), squeeze=False
    )
    layers = [layer_before, None] if show_before else [None]
    for row, layer in enumerate(layers):
        matrix = get_matrix(adata, layer)
        for col, feature in enumerate(features):
            axis = axes[row, col]
            values = matrix[:, adata.var_names.get_loc(feature)]
            for group in adata.obs[groupby].unique():
                selected = values[(adata.obs[groupby] == group).to_numpy()]
                selected = selected[~np.isnan(selected)]
                if kind == "ecdf":
                    axis.plot(np.sort(selected), np.linspace(0, 1, len(selected)), lw=1, label=str(group))
                else:
                    axis.hist(selected, bins=50, histtype="step", density=True, label=str(group))
            axis.set_title(f"{feature}\n{'raw' if layer else 'normalized'}", fontsize=8)
    axes[0, 0].legend(fontsize=6)
    fig.tight_layout()
    return axes


def nan_matrix(adata: AnnData, max_features: int = 200, ax: plt.Axes | None = None):
    """Fraction of NaN per feature per plate."""
    ax = ax or plt.subplots(figsize=(8, 4))[1]
    matrix = np.isnan(get_matrix(adata))
    codes, keys = group_codes(adata, "Metadata_Plate")
    fractions = np.stack([matrix[codes == g].mean(axis=0) for g in range(len(keys))])
    image = ax.imshow(fractions[:, :max_features], aspect="auto", cmap="magma", vmin=0, vmax=1)
    ax.set_yticks(range(len(keys)))
    ax.set_yticklabels([str(k) for k in keys], fontsize=7)
    ax.set_xlabel("feature")
    ax.figure.colorbar(image, ax=ax, label="NaN fraction")
    return ax


def qc(adata: AnnData, figsize: tuple[float, float] = (12, 8)):
    """Two-by-two summary of the 0.1 QC metrics."""
    fig, axes = plt.subplots(2, 2, figsize=figsize)
    cell_counts(adata, ax=axes[0, 0])

    if "qc_n_nan" in adata.var:
        axes[0, 1].hist(adata.var["qc_n_nan"], bins=40)
        axes[0, 1].set_xlabel("NaN cells per feature")

    flags = [c for c in ("qc_is_border", "qc_area_outlier", "qc_pass") if c in adata.obs]
    if flags:
        fractions = adata.obs.groupby("Metadata_Plate", observed=True)[flags].mean()
        fractions.plot.bar(ax=axes[1, 0], legend=True)
        axes[1, 0].set_ylabel("fraction of cells")
        axes[1, 0].legend(fontsize=6)

    if "qc_variance" in adata.var:
        axes[1, 1].hist(np.log10(adata.var["qc_variance"].to_numpy() + 1e-12), bins=40)
        axes[1, 1].set_xlabel("log10 feature variance")

    fig.tight_layout()
    return axes
```

```python
import pandas as pd
import pytest

import mantispy as ms

pycytominer = pytest.importorskip("pycytominer")

def _feature_cols(cells):
    return list(cells.var_names)


@pytest.mark.parametrize("method", ["mad_robustize", "standardize", "robustize"])
def test_normalize_equivalence(cells, frame, method):
    expected = (
        frame.groupby("Metadata_Plate", group_keys=False)
        .apply(
            lambda block: pycytominer.normalize(
                profiles=block,
                features=_feature_cols(cells),
                meta_features=[c for c in block.columns if c.startswith("Metadata_")],
                method=method,
            )
        )
        .loc[frame.index]
    )
    ms.pp.normalize(cells, method=method, by="Metadata_Plate")
    np.testing.assert_allclose(
        cells.X, expected[_feature_cols(cells)].to_numpy(dtype=np.float32), rtol=1e-6, atol=1e-6
    )


def test_normalize_on_controls_equivalence(cells, frame):
    expected = (
        frame.groupby("Metadata_Plate", group_keys=False)
        .apply(
            lambda block: pycytominer.normalize(
                profiles=block,
                features=_feature_cols(cells),

                method="mad_robustize",
                samples="Metadata_Perturbation == 'DMSO'",
            )
        )
        .loc[frame.index]
    )

    np.testing.assert_allclose(
        cells.X, expected[_feature_cols(cells)].to_numpy(dtype=np.float32), rtol=1e-6, atol=1e-6
    )


@pytest.mark.parametrize("func", ["median", "mean"])
@pytest.mark.parametrize("with_nan", [False, True], ids=["clean", "with_nan"])
```

```python
"""BBBC021 CellProfiler profiles."""

from __future__ import annotations

from pathlib import Path

import pandas as pd
import pooch
from anndata import AnnData

from ..io._profiles import from_dataframe

_REGISTRY = pooch.create(
    path=pooch.os_cache("mantispy"),
    base_url="",
    registry={
        # Fill in at implementation time: the exact URL and sha256 of the
        # BBBC021 CellProfiler feature table plus its MOA annotation table.
        # Both must be pinned by hash; pooch verifies on download.
    },
    urls={},
)

NEGATIVE_CONTROLS = ("DMSO",)


def bbbc021(path: str | Path | None = None) -> AnnData:
    """Load the BBBC021 profiles (downloaded and cached on first call)."""
    if path is not None:
        frame = pd.read_csv(path)
    else:
        frame = pd.read_csv(_REGISTRY.fetch("bbbc021_profiles.csv.gz"))
        annotations = pd.read_csv(_REGISTRY.fetch("bbbc021_moa.csv"))
        frame = frame.merge(annotations, on=["Metadata_Compound", "Metadata_Concentration"], how="left")

    adata = from_dataframe(frame, resolution="well")
    adata.obs["Metadata_Control"] = adata.obs["Metadata_Compound"].isin(NEGATIVE_CONTROLS)
    adata.uns["mantispy"]["dataset"] = "BBBC021"
    return adata
```
