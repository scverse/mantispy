# mantispy 0.2.0 "Trustworthy profiles" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete feature selection with full pycytominer semantics, and complete quality control at the image, well and cell level, so that everything from 0.3 onward runs on clean, non-redundant data.

**Architecture:** Feature selection is a set of independent operations each returning a boolean keep-mask over `var`, composed by one driver that writes a single `var["selected"]` column. QC produces boolean flags at three levels (`qc_image_pass` broadcast to cells, `qc_well_pass`, `qc_outlier`) that compose with 0.1's `qc_pass`. Nothing is dropped implicitly — flags are written, filters are explicit calls. All grouped reductions continue to go through `_core._chunks.iter_groups`.

**Tech Stack:** Everything from 0.1 plus scikit-learn (isolation forest, PCA, kNN) and seaborn (clustermap, ECDF/KDE convenience). Dev-only additions: `pyod` (ECOD reference).

**Spec:** `mantispy_release_plan.md` (section "0.2.0 Trustworthy profiles")

**Prerequisite:** `docs/superpowers/plans/2026-09-07-mantispy-0.1.0-foundation.md` complete and released.

## Global Constraints

All 0.1.0 global constraints carry forward unchanged. In addition:

- `pyod`, `scmorph`, `scib` are **test-only**. `tests/test_no_reference_imports.py` already enforces this; add `pyod` was already in its `FORBIDDEN` list — verify it is.
- Feature-selection operations must reproduce pycytominer's results exactly (`rtol=1e-6`), **including the identity of the features removed by the greedy correlation pass**. Removal order is part of the contract.
- No operation may silently reorder `var`. Every selection writes a boolean column; `subset_features` is the only thing that changes shape.
- Image-level information still comes only from `uns["mantispy"]["image_table"]`. No pixels.

```python
# src/mantispy/_core/_corr.py
"""Feature-by-feature correlation with a streamable Gram fast path."""

from __future__ import annotations

import warnings

import numpy as np
import pandas as pd


def _rank_columns(X: np.ndarray) -> np.ndarray:
    return pd.DataFrame(X).rank(axis=0, method="average", na_option="keep").to_numpy()


def _gram_corr(X: np.ndarray, chunk_size: int) -> np.ndarray:
    n_obs, n_vars = X.shape
    total = np.zeros(n_vars, dtype=np.float64)
    gram = np.zeros((n_vars, n_vars), dtype=np.float64)
    for start in range(0, n_obs, chunk_size):
        block = X[start : start + chunk_size].astype(np.float64)
        total += block.sum(axis=0)
        gram += block.T @ block
    mean = total / n_obs
    cov = gram / n_obs - np.outer(mean, mean)
    sd = np.sqrt(np.clip(np.diag(cov), 0.0, None))
    with np.errstate(invalid="ignore", divide="ignore"):
        out = cov / np.outer(sd, sd)
    out[sd == 0, :] = np.nan
    out[:, sd == 0] = np.nan
    np.fill_diagonal(out, np.where(sd == 0, np.nan, 1.0))
    return out


def corr_matrix(
    X: np.ndarray, method: str = "pearson", chunk_size: int = 100_000
) -> np.ndarray:
    """Correlation between the columns of ``X``."""
    if method not in {"pearson", "spearman"}:
        raise ValueError(f"method must be 'pearson' or 'spearman', got {method!r}")
    X = np.asarray(X)
    if method == "spearman":
        X = _rank_columns(X)

    nan_columns = int(np.isnan(X).any(axis=0).sum())
    if nan_columns:
        warnings.warn(
            f"{nan_columns} column(s) contain NaN; falling back to pairwise-complete "
            "correlation, which is slower and not streamable",
            UserWarning,
            stacklevel=2,
        )
        return pd.DataFrame(X).corr(method="pearson").to_numpy()
    return _gram_corr(X, chunk_size)
```

**Interfaces:**
- Consumes: `get_matrix`, `corr_matrix`, `load_blocklist`, `group_codes`, `record_params`
- Produces (each private operation returns a boolean **keep** mask of length `n_vars`):
  - `_op_variance_threshold(X, freq_cut=0.05, unique_cut=0.01) -> ndarray[bool]`
  - `_op_correlation_threshold(X, threshold=0.9, method="pearson") -> ndarray[bool]`
  - `_op_blocklist(var_names, blocklist="default") -> ndarray[bool]`
  - `_op_drop_na_columns(X, cutoff=0.05) -> ndarray[bool]`
  - `_op_drop_outliers(X, cutoff=500.0) -> ndarray[bool]`
  - `_op_noise_removal(X, groups, stdev_cutoff=0.8) -> ndarray[bool]`
  - Public:
    `feature_select(adata, operations=("variance_threshold", "correlation_threshold", "blocklist", "drop_na_columns", "drop_outliers", "noise_removal"), variance_freq_cut=0.05, variance_unique_cut=0.01, corr_threshold=0.9, corr_method="pearson", na_cutoff=0.05, outlier_cutoff=500.0, noise_removal_perturb_groups="Metadata_Perturbation", noise_removal_stdev_cutoff=0.8, blocklist="default", key_added="selected", copy=False) -> AnnData | None`
    Writes `var[key_added]` (bool) and `uns["mantispy"]["feature_select"]` = `{operation: n_removed}`.
    `subset_features(adata, key="selected") -> AnnData` — returns a new object with only the kept features.

**Semantics (the equivalence test in Task 4 is the authority — if pycytominer disagrees, pycytominer wins):**
- *variance_threshold*: drop a feature when `second_most_common_count / most_common_count <= freq_cut` **and** `n_unique / n_rows <= unique_cut`.
- *correlation_threshold*: compute `|corr|`; take every pair above `threshold`, sorted by `|corr|` descending; for each pair where both members survive, drop the member with the higher mean `|corr|` against all features (ties broken by the later `var` position).
- *drop_na_columns*: drop when NaN fraction `> cutoff`.
- *drop_outliers*: drop when `max(|x|) > cutoff` over non-NaN values.
- *noise_removal*: drop when the mean, over perturbation groups, of the per-group standard deviation exceeds `stdev_cutoff`.

```python
# src/mantispy/pp/_select.py
"""Feature selection with pycytominer semantics."""

from __future__ import annotations

from collections.abc import Sequence

import numpy as np
import pandas as pd
from anndata import AnnData

from .._core._chunks import get_matrix, group_codes
from .._core._corr import corr_matrix
from .._core._utils import maybe_copy, record_params
from .._core.features import load_blocklist

OPERATIONS = (
    "variance_threshold", "correlation_threshold", "blocklist",
    "drop_na_columns", "drop_outliers", "noise_removal",
)


def _op_variance_threshold(X: np.ndarray, freq_cut: float = 0.05, unique_cut: float = 0.01):
    n_obs = X.shape[0]
    keep = np.ones(X.shape[1], dtype=bool)
    for j in range(X.shape[1]):
        column = X[:, j]
        column = column[~np.isnan(column)]
        if column.size == 0:
            keep[j] = False
            continue
        counts = np.sort(np.unique(column, return_counts=True)[1])[::-1]
        freq_ratio = counts[1] / counts[0] if counts.size > 1 else 0.0
        unique_ratio = counts.size / n_obs
        keep[j] = not (freq_ratio <= freq_cut and unique_ratio <= unique_cut)
    return keep


def _op_correlation_threshold(X: np.ndarray, threshold: float = 0.9, method: str = "pearson"):
    corr = np.abs(corr_matrix(X, method=method))
    np.fill_diagonal(corr, 0.0)
    corr = np.nan_to_num(corr, nan=0.0)
    mean_corr = corr.mean(axis=1)

    rows, cols = np.triu_indices_from(corr, k=1)
    above = corr[rows, cols] > threshold
    rows, cols = rows[above], cols[above]
    order = np.argsort(-corr[rows, cols], kind="stable")

    keep = np.ones(X.shape[1], dtype=bool)
    for i, j in zip(rows[order], cols[order], strict=True):
        if not (keep[i] and keep[j]):
            continue
        if mean_corr[i] > mean_corr[j] or (mean_corr[i] == mean_corr[j] and i < j):
            keep[i] = False
        else:
            keep[j] = False
    return keep


def _op_blocklist(var_names, blocklist: str | Sequence[str] = "default"):
    blocked = set(load_blocklist() if blocklist == "default" else blocklist)
    return ~np.isin(np.asarray(var_names), list(blocked))


def _op_drop_na_columns(X: np.ndarray, cutoff: float = 0.05):
    return np.isnan(X).mean(axis=0) <= cutoff


def _op_drop_outliers(X: np.ndarray, cutoff: float = 500.0):
    with np.errstate(invalid="ignore"):
        return ~(np.nanmax(np.abs(X), axis=0) > cutoff)


def _op_noise_removal(X: np.ndarray, groups: np.ndarray, stdev_cutoff: float = 0.8):
    n_groups = int(groups.max()) + 1
    stdevs = np.stack(
        [np.nanstd(X[groups == g], axis=0, ddof=1) if (groups == g).sum() > 1
         else np.zeros(X.shape[1]) for g in range(n_groups)]
    )
    return np.nan_to_num(stdevs.mean(axis=0), nan=np.inf) <= stdev_cutoff


def feature_select(
    adata: AnnData,
    operations: Sequence[str] = OPERATIONS,
    variance_freq_cut: float = 0.05,
    variance_unique_cut: float = 0.01,
    corr_threshold: float = 0.9,
    corr_method: str = "pearson",
    na_cutoff: float = 0.05,
    outlier_cutoff: float = 500.0,
    noise_removal_perturb_groups: str = "Metadata_Perturbation",
    noise_removal_stdev_cutoff: float = 0.8,
    blocklist: str | Sequence[str] = "default",
    key_added: str = "selected",
    copy: bool = False,
) -> AnnData | None:
    """Run feature-selection operations and write a boolean ``var`` column."""
    unknown = set(operations) - set(OPERATIONS)
    if unknown:
        raise ValueError(f"unknown operation(s): {sorted(unknown)}; choose from {OPERATIONS}")
    adata = maybe_copy(adata, copy)

    X = get_matrix(adata)
    keep = np.ones(adata.n_vars, dtype=bool)
    removed: dict[str, int] = {}

    for operation in operations:
        before = keep.copy()
        if operation == "variance_threshold":
            keep &= _op_variance_threshold(X, variance_freq_cut, variance_unique_cut)
        elif operation == "correlation_threshold":
            mask = np.ones(adata.n_vars, dtype=bool)
            mask[keep] = _op_correlation_threshold(X[:, keep], corr_threshold, corr_method)
            keep &= mask
        elif operation == "blocklist":
            keep &= _op_blocklist(adata.var_names.to_numpy(), blocklist)
        elif operation == "drop_na_columns":
            keep &= _op_drop_na_columns(X, na_cutoff)
        elif operation == "drop_outliers":
            keep &= _op_drop_outliers(X, outlier_cutoff)
        elif operation == "noise_removal":
            if noise_removal_perturb_groups not in adata.obs:
                raise KeyError(f"obs has no column {noise_removal_perturb_groups!r}")
            codes, _ = group_codes(adata, noise_removal_perturb_groups)
            keep &= _op_noise_removal(X, codes, noise_removal_stdev_cutoff)
        removed[operation] = int((before & ~keep).sum())

    adata.var[key_added] = keep
    adata.uns.setdefault("mantispy", {})["feature_select"] = removed
    record_params(
        adata,
        "feature_select",
        {
            "operations": list(operations), "variance_freq_cut": variance_freq_cut,
            "variance_unique_cut": variance_unique_cut, "corr_threshold": corr_threshold,
            "corr_method": corr_method, "na_cutoff": na_cutoff, "outlier_cutoff": outlier_cutoff,
            "noise_removal_stdev_cutoff": noise_removal_stdev_cutoff, "key_added": key_added,
        },
    )
    return adata if copy else None


def subset_features(adata: AnnData, key: str = "selected") -> AnnData:
    """Return a new object holding only the features flagged by ``var[key]``."""
    if key not in adata.var:
        raise KeyError(f"var has no column {key!r}; run ms.pp.feature_select first")
    return adata[:, adata.var[key].to_numpy(dtype=bool)].copy()
```

```python
# src/mantispy/_core/_ecod.py
"""Empirical-cumulative-distribution outlier detection (Li et al. 2022)."""

from __future__ import annotations

import numpy as np
from scipy.stats import skew


def _ecdf(column: np.ndarray) -> np.ndarray:
    """Left-tail empirical CDF, ties sharing the maximum rank, in ``[1/n, 1]``."""
    n = column.shape[0]
    order = np.argsort(column, kind="stable")
    ranks = np.empty(n, dtype=np.float64)
    sorted_values = column[order]
    # ties take the highest rank, matching the standard ECDF definition
    _, starts, counts = np.unique(sorted_values, return_index=True, return_counts=True)
    cumulative = np.cumsum(counts)
    for start, count, upto in zip(starts, counts, cumulative, strict=True):
        ranks[order[start : start + count]] = upto
    return ranks / n


def ecod_scores(X: np.ndarray) -> np.ndarray:
    """ECOD outlier score per row of ``X`` (higher is more outlying)."""
    X = np.asarray(X, dtype=np.float64)
    n_obs, n_vars = X.shape
    left = np.zeros((n_obs, n_vars))
    right = np.zeros((n_obs, n_vars))

    for j in range(n_vars):
        column = X[:, j]
        finite = ~np.isnan(column)
        if not finite.any():
            continue
        left[finite, j] = -np.log(_ecdf(column[finite]))
        right[finite, j] = -np.log(_ecdf(-column[finite]))

    skewness = skew(np.nan_to_num(X, nan=0.0), axis=0)
    auto = np.where(skewness < 0, left, right)

    return np.maximum.reduce([left.sum(axis=1), right.sum(axis=1), auto.sum(axis=1)])
```

```python
# src/mantispy/pp/_outliers.py
"""Cell-level outlier detection."""

from __future__ import annotations

import numpy as np
from anndata import AnnData
from sklearn.ensemble import IsolationForest

from .._core._chunks import get_matrix, group_codes
from .._core._ecod import ecod_scores
from .._core._utils import get_logger, maybe_copy, record_params

METHODS = ("ecod", "isolation_forest", "mad")


def _scores(X: np.ndarray, method: str, seed: int) -> np.ndarray:
    if method == "ecod":
        return ecod_scores(X)
    if method == "isolation_forest":
        model = IsolationForest(random_state=seed, n_estimators=200)
        model.fit(np.nan_to_num(X, nan=0.0))
        return -model.score_samples(np.nan_to_num(X, nan=0.0))
    median = np.nanmedian(X, axis=0)
    mad = 1.4826 * np.nanmedian(np.abs(X - median), axis=0)
    with np.errstate(invalid="ignore", divide="ignore"):
        z = np.abs(X - median) / mad
    return np.nanmax(np.nan_to_num(z, nan=0.0, posinf=0.0), axis=1)


def outliers(
    adata: AnnData,
    method: str = "ecod",
    contamination: float = 0.01,
    key: str | None = "selected",
    by: str | None = None,
    key_added: str = "qc_outlier",
    seed: int = 0,
    copy: bool = False,
) -> AnnData | None:
    """Flag outlying cells."""
    if method not in METHODS:
        raise ValueError(f"method must be one of {METHODS}, got {method!r}")
    adata = maybe_copy(adata, copy)

    if key is not None and key in adata.var:
        mask = adata.var[key].to_numpy(dtype=bool)
    else:
        if key is not None:
            get_logger().debug("var has no column %r; using all features", key)
        mask = np.ones(adata.n_vars, dtype=bool)
    X = get_matrix(adata)[:, mask]

    scores = np.empty(adata.n_obs, dtype=np.float64)
    flag = np.zeros(adata.n_obs, dtype=bool)
    codes, keys = group_codes(adata, by)
    for g in range(len(keys)):
        rows = np.flatnonzero(codes == g)
        block_scores = _scores(X[rows], method, seed)
        scores[rows] = block_scores
        if method == "mad":
            flag[rows] = block_scores > 5.0
        else:
            flag[rows] = block_scores >= np.quantile(block_scores, 1.0 - contamination)

    adata.obs[key_added] = flag
    adata.obs[f"{key_added}_score"] = scores
    record_params(
        adata,
        "outliers",
        {
            "method": method, "contamination": contamination, "key": key, "by": by,
            "key_added": key_added, "n_features_used": int(mask.sum()),
        },
    )
    return adata if copy else None
```

```python
"""Image-level quality control from CellProfiler MeasureImageQuality columns."""

from __future__ import annotations

import warnings
from collections.abc import Sequence

import numpy as np
import pandas as pd
from anndata import AnnData
from sklearn.neighbors import NearestNeighbors

from .._core._utils import maybe_copy, record_params

DEFAULT_METRICS = ("FocusScore", "PowerLogLogSlope", "PercentMaximal", "PercentMinimal", "Saturation")


def _metric_columns(table: pd.DataFrame, metrics: Sequence[str], channel: str | None) -> list[str]:
    columns = []
    for column in table.columns:
        if not any(f"ImageQuality_{metric}" in column for metric in metrics):
            continue
        if channel is not None and not column.endswith(f"_{channel}"):
            continue
        columns.append(column)
    if not columns:
        raise KeyError(
            f"image table has no ImageQuality columns for metrics={list(metrics)} channel={channel!r}"
        )
    return columns


def _robust_z(values: np.ndarray) -> np.ndarray:
    median = np.nanmedian(values, axis=0)
    mad = 1.4826 * np.nanmedian(np.abs(values - median), axis=0)
    with np.errstate(invalid="ignore", divide="ignore"):
        return np.abs(values - median) / mad


def image_qc(
    adata: AnnData,
    metrics: Sequence[str] = DEFAULT_METRICS,
    channel: str | None = None,
    method: str = "mad",
    threshold: float | str = "auto",
    by: str | None = "Metadata_Plate",
    k: int = 15,
    copy: bool = False,
) -> AnnData | None:
    """Flag low-quality images from the CellProfiler image table."""
    if method not in {"mad", "knn"}:
        raise ValueError(f"method must be 'mad' or 'knn', got {method!r}")
    adata = maybe_copy(adata, copy)

    store = adata.uns.get("mantispy", {})
    if "image_table" not in store:
        raise KeyError("uns['mantispy']['image_table'] is missing; read with ms.io.read_cellprofiler")
    table = store["image_table"].copy()

    columns = _metric_columns(table, metrics, channel)
    values = table[columns].to_numpy(dtype=np.float64)

    groups = (
        table[by].to_numpy() if by is not None and by in table.columns
        else np.zeros(len(table), dtype=int)
    )

    score = np.zeros(len(table))
    passed = np.ones(len(table), dtype=bool)
    for group in np.unique(groups):
        rows = np.flatnonzero(groups == group)
        block = values[rows]
        if method == "mad":
            z = _robust_z(block)
            block_score = np.nanmax(np.nan_to_num(z, nan=0.0, posinf=0.0), axis=1)
            cutoff = 5.0 if threshold == "auto" else float(threshold)
        else:
            centered = (block - np.nanmean(block, axis=0)) / np.nanstd(block, axis=0)
            centered = np.nan_to_num(centered, nan=0.0)
            n_neighbors = min(k + 1, len(rows))
            distances, _ = NearestNeighbors(n_neighbors=n_neighbors).fit(centered).kneighbors(centered)
            block_score = distances[:, 1:].mean(axis=1)
            median = np.median(block_score)
            mad = 1.4826 * np.median(np.abs(block_score - median))
            cutoff = median + 5.0 * mad if threshold == "auto" else float(threshold)
        score[rows] = block_score
        passed[rows] = block_score <= cutoff

    table["qc_image_score"] = score
    table["qc_image_pass"] = passed
    store["image_qc"] = table

    if "Metadata_ImageNumber" not in adata.obs:
        raise KeyError("obs has no 'Metadata_ImageNumber' column to broadcast image QC onto")
    lookup = table["qc_image_pass"]
    broadcast = adata.obs["Metadata_ImageNumber"].map(lookup)
    n_missing = int(broadcast.isna().sum())
    if n_missing:
        warnings.warn(
            f"{n_missing} cells have an ImageNumber not present in the image table; "
            "they are treated as passing",
            UserWarning,
            stacklevel=2,
        )
    adata.obs["qc_image_pass"] = broadcast.fillna(True).astype(bool)

    record_params(
        adata,
        "image_qc",
        {
            "metrics": list(metrics), "channel": channel, "method": method,
            "threshold": threshold, "by": by, "k": k, "n_flagged": int((~passed).sum()),
        },
    )
    return adata if copy else None


def filter_images(adata: AnnData, copy: bool = False) -> AnnData | None:
    """Drop every cell belonging to an image that failed :func:`image_qc`."""
    if "qc_image_pass" not in adata.obs:
        raise KeyError("run ms.pp.image_qc first")
    result = adata[adata.obs["qc_image_pass"].to_numpy(dtype=bool)].copy()
    record_params(result, "filter_images", {"n_dropped": int(adata.n_obs - result.n_obs)})
    if copy:
        return result
    adata._init_as_actual(result)
    return None
```

```python
# src/mantispy/pp/_well_qc.py
"""Well-level quality control."""

from __future__ import annotations

import numpy as np
import pandas as pd
from anndata import AnnData

from .._core._chunks import get_matrix, group_codes
from .._core._utils import maybe_copy, record_params


def well_qc(
    adata: AnnData,
    min_cells: int = 50,
    max_control_cv: float | None = None,
    max_nan_fraction: float = 0.1,
    key: str | None = "selected",
    copy: bool = False,
) -> AnnData | None:
    """Flag wells with too few cells, too many NaN, or unstable controls."""
    adata = maybe_copy(adata, copy)

    mask = (
        adata.var[key].to_numpy(dtype=bool)
        if key is not None and key in adata.var
        else np.ones(adata.n_vars, dtype=bool)
    )
    X = get_matrix(adata)[:, mask]
    codes, keys = group_codes(adata, ["Metadata_Plate", "Metadata_Well"])
    is_control = (
        adata.obs["Metadata_Control"].to_numpy(dtype=bool)
        if "Metadata_Control" in adata.obs
        else np.zeros(adata.n_obs, dtype=bool)
    )

    rows = []
    for g in range(len(keys)):
        selected = codes == g
        block = X[selected]
        control_cv = np.nan
        if is_control[selected].any() and block.shape[0] > 1:
            mean = np.nanmean(block, axis=0)
            sd = np.nanstd(block, axis=0, ddof=1)
            with np.errstate(invalid="ignore", divide="ignore"):
                control_cv = float(np.nanmedian(np.abs(sd / mean)))
        rows.append(
            {
                "n_cells": int(selected.sum()),
                "nan_fraction": float(np.isnan(block).mean()) if block.size else 1.0,
                "control_cv": control_cv,
            }
        )

    table = pd.DataFrame(rows, index=keys)
    passed = (table["n_cells"] >= min_cells) & (table["nan_fraction"] <= max_nan_fraction)
    if max_control_cv is not None:
        passed &= table["control_cv"].isna() | (table["control_cv"] <= max_control_cv)
    table["qc_well_pass"] = passed

    adata.uns.setdefault("mantispy", {})["well_qc"] = table
    adata.obs["qc_well_pass"] = table["qc_well_pass"].to_numpy()[codes]

    record_params(
        adata,
        "well_qc",
        {
            "min_cells": min_cells, "max_control_cv": max_control_cv,
            "max_nan_fraction": max_nan_fraction, "key": key,
            "n_failed": int((~passed).sum()),
        },
    )
    return adata if copy else None
```

```python
# src/mantispy/pp/_names.py
"""Rename features to a canonical grammar."""

from __future__ import annotations

import numpy as np
import pandas as pd
from anndata import AnnData

from .._core._utils import maybe_copy, record_params


def _canonical(row: pd.Series) -> str:
    parts = [row["object"], row["feature_group"], row["feature"], row["channel"]]
    parts = [str(p) for p in parts if isinstance(p, str) and p]
    for key in ("scale", "angle", "gray_levels"):
        value = row.get(key)
        if value is not None and not pd.isna(value):
            parts.append(f"{int(value)}" if float(value).is_integer() else f"{value}")
    if isinstance(row.get("radial_bin"), str):
        parts.append(row["radial_bin"])
    return "_".join(parts)


def standardize_feature_names(
    adata: AnnData, target: str = "cp_measure", copy: bool = False
) -> AnnData | None:
    """Rename features to ``target`` grammar, keeping the original in ``var``."""
    if target != "cp_measure":
        raise ValueError(f"target must be 'cp_measure', got {target!r}")
    adata = maybe_copy(adata, copy)

    if "original_name" not in adata.var:
        adata.var["original_name"] = adata.var_names.to_numpy()

    new_names = [
        _canonical(row) if row["is_feature"] else name
        for name, row in zip(adata.var_names, adata.var.to_dict("records"), strict=True)
    ]
    values, counts = np.unique(new_names, return_counts=True)
    collisions = values[counts > 1].tolist()
    if collisions:
        raise ValueError(f"renaming would create name collision(s): {collisions[:5]}")

    adata.var_names = pd.Index(new_names)
    record_params(adata, "standardize_feature_names", {"target": target})
    return adata if copy else None
```
